# 02 — 玩家将一至十份成品上架到空吧台

**What to build:** 玩家可以在空吧台选择成品饮品并创建销售批次。库存达到十份时扣除十份；库存为一至九份时可全部直接上架，或跳转到保持默认数量一份的普通制作台。上架必须使用 JWT 身份并保证库存和批次原子一致。

**Blocked by:** 01 — 建立六个室外吧台与销售批次状态

**Status:** resolved

## Acceptance criteria

- [ ] 只有空闲吧台可以上架
- [ ] 同一批次只能上架一种成品饮品
- [ ] 库存不少于十份时固定扣除并上架十份
- [ ] 库存一至九份时直接上架会扣除并上架当前全部数量
- [ ] 库存为零时拒绝上架且不产生批次
- [ ] 上架确认展示单份和整批预计金币、经验
- [ ] 上架时锁定金币、经验和 180 秒销售间隔快照
- [ ] 同一种饮品可以同时上架到多个吧台，各自独立扣货
- [ ] 重复或并发上架不会造成负库存、重复扣货或一桌多批次
- [ ] 所有写操作使用 JWT 玩家身份
- [ ] 客户端库存不足十份时同时提供“直接上架”和“去制作”
- [ ] “去制作”只打开普通制作台，不预选配方且数量默认一份
- [ ] 库存为零时只显示“去制作”
- [ ] 操作后刷新吧台和背包
