# 03 — 按时间补算销售并支持下架

**What to build:** 服务端使用批次时间戳和销售间隔快照惰性计算在线与离线销售进度。玩家可随时下架未售完批次，取回未售成品并结算已售金币、经验和升级奖励。

**Blocked by:** 02 — 玩家将一至十份成品上架到空吧台

**Status:** resolved

## Acceptance criteria

- [ ] 上架后 179 秒仍未售出，满 180 秒售出第一份
- [ ] 每经过完整 180 秒增加一份已售数量
- [ ] 已售数量不得超过该批次上架数量
- [ ] 满批十份最早在三十分钟售罄，小批次按实际数量结束
- [ ] 每个吧台独立按自身上架时间和间隔快照推进
- [ ] 长时间离线后一次读取可准确补算到当前状态
- [ ] 后台修改销售间隔后旧批次按旧快照、新批次按新配置
- [ ] 部分售出批次不能正常收取
- [ ] 未售完批次可随时下架并二次确认
- [ ] 下架退回全部未售成品，只按已售数量结算收益
- [ ] 零售出下架时全部成品退回且不发收益
- [ ] 下架后吧台立即空闲，可以重新上架
- [ ] 下架的退货、收益、升级与批次关闭在一个事务中完成
- [ ] 重复或并发下架不会重复退货或发奖
- [ ] 客户端展示剩余数量、已售数量、待收收益和下一份倒计时
- [ ] 操作后刷新吧台、背包、金币、经验和等级
