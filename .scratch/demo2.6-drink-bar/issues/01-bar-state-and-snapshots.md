# 01 — 建立六个室外吧台与销售批次状态

**What to build:** 为每位玩家提供六个默认开放的室外吧台，建立可保留历史的销售批次、草莓汁每 180 秒售出一份的配置，以及上架时的金币、玩家经验和销售间隔快照。提供 JWT 读取接口，返回六个吧台的权威状态。

**Blocked by:** None — can start immediately

**Status:** resolved

## Acceptance criteria

- [ ] 每位玩家始终拥有编号稳定且不重复的六个吧台
- [ ] 六个吧台默认全部开放，不依赖玩家等级或饮品店等级
- [ ] 批次保存玩家、吧台、配方、成品、上架数量、已售数量、状态及关键时间
- [ ] 批次保存单份金币、单份玩家经验和销售间隔快照
- [ ] 草莓汁默认销售间隔配置为 180 秒/份
- [ ] 同一吧台最多存在一个未关闭批次，不同吧台允许同一种饮品
- [ ] 售罄待收取批次继续占用吧台，历史记录不会被覆盖
- [ ] JWT 读取接口只返回当前玩家的六个吧台
- [ ] 返回状态足以表达空闲、售卖中和售罄待收取
- [ ] 数据迁移兼容已有玩家且可安全补齐六个吧台
- [ ] 服务端行为测试覆盖初始化幂等、玩家隔离和快照字段
