# 04 — 收取售罄收益并呈现室外吧台交互

**What to build:** 玩家可以单独收取一个售罄吧台或一键收取全部售罄吧台。地图在饮品店小屋左侧和右侧各呈现三套可点击桌椅，并通过统一入口打开六个吧台总览。

**Blocked by:** 03 — 按时间补算销售并支持下架

**Status:** resolved

## Acceptance criteria

- [ ] 只有已经全部售罄的批次可以正常收取
- [ ] 单独收取只结算目标吧台并将其恢复为空闲
- [ ] 一键收取至少需要一个售罄吧台
- [ ] 一键收取只处理调用时已售罄的吧台
- [ ] 未售罄吧台在一键收取后保持原批次和销售进度
- [ ] 多个售罄批次的金币和经验汇总后统一执行玩家升级
- [ ] 重复或并发收取不会重复发放收益或清空错误批次
- [ ] 所有写操作使用 JWT 玩家身份
- [ ] 饮品店小屋左侧三套、右侧三套桌椅，中间入口和通道保持可用
- [ ] 六套桌椅可以直接点击打开对应吧台详情
- [ ] 统一“吧台”入口打开六个吧台总览
- [ ] 统一入口角标显示可收取吧台数量
- [ ] 地图只以空桌、饮品托盘、金币提示表达空闲、售卖中、待收取
- [ ] 数量、收益和倒计时只在点击后的详情或总览展示
- [ ] 登录不自动弹窗或结算，只刷新角标和服务端补算后的状态
- [ ] 不实现室内场景、室内移动或顾客 NPC 动画
- [ ] 完成后运行完整服务端测试、客户端 TypeScript、客户端回归测试、页面脚本检查和真实 JWT HTTP/页面验证
