# 01 — 玩家通过制作台制作草莓汁

**What to build:** 让玩家通过饮品店制作台完成首个可玩的制作闭环。所有玩家永久拥有草莓汁初始配方，可以选择 1–99 份制作数量，按每份消耗草莓 ×2，制作出的草莓汁全部进入背包。制作本身不产生金币或玩家经验。

**Blocked by:** None — can start immediately

**Status:** resolved

## Acceptance criteria

- [ ] 新玩家初始化时永久获得草莓汁配方
- [ ] 现有玩家缺少草莓汁配方时能够幂等补发
- [ ] 制作台展示配方、材料需求、库存和最大可制作数量
- [ ] 默认制作 1 份，支持增加、减少和“最大”，单次范围为 1–99
- [ ] 每制作 1 份草莓汁扣除草莓 ×2，并向背包增加草莓汁 ×1
- [ ] 材料不足、数量非法或没有配方资格时不产生部分扣除或成品
- [ ] 制作成功后金币和玩家经验保持不变
- [ ] 所有写操作使用 JWT 对应的玩家身份
- [ ] 服务端行为测试、客户端 TypeScript 和页面脚本检查通过
