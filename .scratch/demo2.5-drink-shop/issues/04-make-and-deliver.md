# 04 — 玩家现场制作并完整交付顾客订单

**What to build:** 背包成品不足时，玩家可以针对顾客订单选择现场制作数量。制作数量必须覆盖完整订单，材料一次性扣除，订单需要的成品立即售出，多余成品进入背包，并按收益快照完成金币和玩家经验结算。

**Blocked by:** 03 — 玩家使用背包成品完整交付顾客订单

**Status:** resolved

## Acceptance criteria

- [ ] 现场制作数量范围为 1–99，且不得少于订单需求
- [ ] 材料必须覆盖玩家选择制作的全部数量
- [ ] 背包中的不足成品不与现场制作混合使用
- [ ] 订单需要的成品立即售出，多余成品进入背包
- [ ] 材料不足、数量非法、订单已关闭或配方无效时不产生部分写入
- [ ] 金币、玩家经验、升级奖励和订单关闭在同一事务中完成
- [ ] 重复请求或并发提交不会重复扣料、增加成品或发放收益
- [ ] 客户端显示材料消耗、制作数量、交付数量和多余入包数量
- [ ] 完成后刷新背包、金币、经验、等级和顾客队列
