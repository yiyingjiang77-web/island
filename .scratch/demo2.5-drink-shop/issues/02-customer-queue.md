# 02 — 玩家看到持续补位的顾客队列

**What to build:** 玩家首次进入饮品店时立即看到五位顾客，并能操作任意顾客。订单从玩家当前有效的配方资格中按配置权重生成，数量按配置权重选择 1–3 份。队列满员时停止计时，出现空位后每两分钟补充一位，离线期间按同一规则补算且最多五位。

**Blocked by:** 01 — 玩家通过制作台制作草莓汁

**Status:** resolved

## Acceptance criteria

- [ ] 首次进入饮品店立即生成五位顾客
- [ ] 五位顾客均可选择和查看，不限制只能操作队首
- [ ] Demo2.5 的订单只生成草莓汁
- [ ] 订单数量按 1 份 60%、2 份 30%、3 份 10% 的可配置权重生成
- [ ] 订单配方按可配置权重生成，不检查材料或成品库存
- [ ] 顾客没有等待期限，不会自动关闭订单
- [ ] 满员时停止到店计时，出现空位后从两分钟重新计时
- [ ] 每轮计时只补充一位，满员期间不积攒补位
- [ ] 离线补算遵循相同规则且不会超过五位
- [ ] 客户端显示顾客、订单数量、预计收益和下一位顾客倒计时
- [ ] 时间相关测试使用可控制的服务端时间来源
