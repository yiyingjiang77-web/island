# 03 — 玩家使用背包成品完整交付顾客订单

**What to build:** 背包中拥有足量对应成品时，玩家可以一次完整交付顾客订单。交付按订单生成时锁定的收益快照发放金币和玩家经验，执行玩家升级及升级金币结算，并同步刷新背包、玩家状态和顾客队列。

**Blocked by:** 02 — 玩家看到持续补位的顾客队列

**Status:** resolved

## Acceptance criteria

- [ ] 订单生成时保存单份金币和单份玩家经验快照
- [ ] 背包成品足够时一次扣除订单要求的全部数量并关闭订单
- [ ] 背包成品不足时拒绝操作，不支持部分交付
- [ ] 每售出一份草莓汁获得 30 金币和 5 玩家经验
- [ ] 多份订单按数量线性结算
- [ ] 玩家经验沿用现有升级和升级金币机制
- [ ] 后台修改收益后，旧订单按旧快照结算，新订单使用新配置
- [ ] 重复请求或并发提交不会重复扣货、关闭订单或发放收益
- [ ] 客户端刷新背包、金币、经验、等级和顾客队列
- [ ] HTTP 层验证 JWT 玩家身份和请求响应契约
