# 05 — 玩家以“暂时没货”关闭顾客订单

**What to build:** 玩家无法或不愿满足某张等待订单时，可以选择“暂时没货”。顾客立即离开，订单以明确的拒绝结果关闭，不扣金币或玩家经验，也不发放奖励；队列出现空位后按两分钟规则补位。

**Blocked by:** 02 — 玩家看到持续补位的顾客队列

**Status:** resolved

## Acceptance criteria

- [ ] 任意等待中的顾客订单都可以选择“暂时没货”
- [ ] 操作后顾客立即离开，订单记录明确的关闭状态、原因和时间
- [ ] 操作不扣金币、不扣玩家经验，也不发放奖励
- [ ] 已关闭订单不能被重复关闭或继续交付
- [ ] 队列中其他顾客前移，空位从关闭时刻开始两分钟计时
- [ ] 关闭结果能够支持 Demo2.7 统计拒单率和每日满意度
- [ ] 客户端刷新顾客队列和下一位顾客倒计时
- [ ] 服务端测试覆盖重复请求、非本人订单和已关闭订单
