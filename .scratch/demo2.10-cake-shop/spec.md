# Demo2.10 蛋糕店与室外蛋糕架

**Status:** ready-for-agent  
**重写日期:** 2026-08-01（基于 Demo3.0 设计重写原 Demo2.10）

## Problem Statement

玩家通过岛屿等级奖励和兑换商店获得了蛋糕类配方资格，通过 Demo2.9 获得了牛奶和鸡蛋的生产能力，但还没有可以消费这些材料的完整蛋糕经营循环。蛋糕店缺少金币装修、蛋糕制作、两个室外蛋糕架、离线销售和收益收取能力。

## Solution

在 Demo2.7–2.9 的小岛成长、作物和畜牧能力之上建设蛋糕店。玩家达到岛屿 Lv8 后花费金币逐级装修蛋糕店，**装修解锁制作能力而非配方**（配方来自岛屿等级奖励 + 兑换商店的独立体系）。蛋糕店可制作玩家已拥有配方资格的所有蛋糕类配方。制作完成的蛋糕可上架到两个独立的室外蛋糕架，按锁定快照在线或离线售卖。

> **Demo3.0 对齐说明（核心改动 vs 原 Demo2.10）：**
> - **装修不再解锁配方**：蛋糕配方来自岛屿等级奖励（基础）+ 兑换商店金币购买（花卉 + 菌菇）。蛋糕店装修只解锁制作能力和经营性提升
> - **配方体制**：蛋糕类配方是 Demo3.0 35 配方体系的一部分（基础 11 中有蛋糕、花卉 16 中有蛋糕、菌菇 8 中有蛋糕）
> - **经济数值**：蛋糕售价、蛋糕架销售收益使用 Demo3.0 经济重平衡标准

### 2.2 制作规则

- 在蛋糕店制作台选择已拥有配方资格的**蛋糕类**配方
- 制作数量默认为 1 份，最多不超过材料可制作数量
- 按配方配置扣除材料（作物、牛奶、鸡蛋、蜂蜜、花卉等）
- 制作完成的蛋糕按"份"存入背包
- 制作本身不产生金币或玩家经验（收益来自蛋糕架售出）
- 材料不足时制作按钮禁用
- 材料扣减与蛋糕入库处于同一事务

## 第三章：室外蛋糕架

### 3.1 基本规则

- 两个蛋糕架，编号稳定且唯一（slot_1、slot_2）
- 从蛋糕店一级起全部可用
- 同一架子最多一个未关闭批次（上架中/销售中/售罄）
- 不同架子可上架相同或不同蛋糕
- 每批只能上架同一种蛋糕，至少 1 份

### 3.2 上架规则

- 上架数量不能超过背包库存
- 上架数量不能超过当前蛋糕店等级的单架上限（Lv1=8 → Lv10=15）
- 上架时锁定快照：蛋糕种类、数量、单份金币（配方售价）、单份经验、销售间隔
- 已售卖中的架子不能补货或换品（需等下架或售罄收取后）
- 上架扣减背包蛋糕，原子事务

### 3.3 销售规则

- 第一份蛋糕必须经过完整销售间隔后才售出
- 售出份数 = 经过时间 / 销售间隔，向下取整，不超过上架数量
- 在线和离线使用同一补算规则（惰性结算，按服务器时间）
- 全部售出后进入"售罄待收取"状态
- 已上架批次不受后台调价或调间隔影响（快照锁定）

### 3.4 收取与下架

- **收取**（售罄后）：结算全部快照金币和经验，清空架子
- **下架**（未售罄）：结算已售部分金币和经验，退回未售蛋糕到背包
- 金币和经验结算可触发岛屿连续升级
- 重复或并发收取/下架最多成功一次

## 第四章：配方与建筑能力分离

### 4.1 设计原则

| 概念 | 来源 | 说明 |
|------|------|------|
| **配方资格** | 岛屿等级奖励 + 兑换商店 + NPC 奖励 | 玩家"知道怎么做"这个配方 |
| **制作能力** | 建筑装修等级 | 玩家"有设备可以做"蛋糕/饮品 |
| **制作入口** | 蛋糕店 / 饮品店 | 配方标记为 `cake` 或 `drink` 类型 |

- 玩家可以拥有配方资格但没有制作能力（如岛Lv5就获得了草莓蛋糕配方资格，但岛Lv8才能解锁蛋糕店制作能力）
- 已拥有但暂不可制作的配方保持可见，展示缺少的建筑条件
- "制作入口"字段区分配方属于饮品店还是蛋糕店

### 4.2 配方资格数据模型

```sql
-- player_recipe 表（已存在于 Demo2.7）
CREATE TABLE player_recipe (
  id BIGINT PRIMARY KEY,
  player_id BIGINT NOT NULL,
  recipe_id BIGINT NOT NULL,
  obtained_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  UNIQUE KEY uk_player_recipe (player_id, recipe_id)
);
```

`recipe_config` 表新增字段：
- `craft_station` VARCHAR(16)：制作入口，取值 `drink_bar`（饮品店）/ `cake_shop`（蛋糕店）
- `obtain_channel` VARCHAR(32)：获取渠道，取值 `island_level` / `exchange_shop` / `npc_reward`
