# Demo2.10 蛋糕店与室外蛋糕架

**Status:** ready-for-agent

## Problem Statement

玩家在小岛八级获得草莓蛋糕配方和小麦种植权后，还没有可以消费鸡蛋、小麦和水果的完整蛋糕经营循环。蛋糕店缺少金币装修、蛋糕制作、两个室外蛋糕架、离线销售和收益收取能力，玩家无法把前序版本积累的作物、牛奶和鸡蛋加工成高价值成品。

## Solution

在 Demo2.7–2.9 的小岛成长、作物和畜牧能力之上建设蛋糕店。玩家达到相应小岛等级后花费金币逐级装修蛋糕店，获得制作能力和固定店铺配方；在蛋糕店按份制作蛋糕并存入背包，再将同一种蛋糕上架到两个独立的室外蛋糕架。蛋糕架按照上架时锁定的数量、单份金币、玩家经验和销售间隔在线或离线售卖，售罄后收取收益，也可提前下架并取回未售库存。

## User Stories

1. As a 玩家, I want 小岛八级时看到草莓蛋糕配方, so that 我知道新的蛋糕成长目标。
2. As a 玩家, I want 未解锁蛋糕店时仍能查看草莓蛋糕配方和所缺条件, so that 我知道如何开始蛋糕经营。
3. As a 玩家, I want 达到小岛八级后花费金币解锁一级蛋糕店, so that 小岛等级不会自动替我消费金币。
4. As a 玩家, I want 蛋糕店必须逐级装修, so that 成长过程清晰且不能跳过成本。
5. As a 玩家, I want 装修前预览所需小岛等级、金币和奖励, so that 我能规划资源。
6. As a 玩家, I want 金币不足或小岛等级不足时看到准确提示, so that 我知道缺少什么。
7. As a 玩家, I want 一级蛋糕店开放草莓蛋糕制作, so that 八级赠送配方可以实际使用。
8. As a 玩家, I want 二至十级装修固定解锁对应蛋糕配方, so that 每级都有明确奖励。
9. As a 玩家, I want 店铺升级配方不能提前购买, so that 装修奖励保持独特。
10. As a 玩家, I want 已获得但暂不可制作的配方保持可见, so that 配方不会因材料或店铺条件暂缺而消失。
11. As a 玩家, I want 在制作台选择蛋糕配方和数量, so that 我可以按需要批量制作。
12. As a 玩家, I want 制作数量默认为一份, so that 普通操作简单。
13. As a 玩家, I want 制作数量不能超过材料可制作数量, so that 不会产生负库存。
14. As a 玩家, I want 材料不足时数量控件和制作操作正确禁用, so that 页面不会提交无效请求。
15. As a 玩家, I want 制作一份蛋糕准确扣除配置材料, so that 草莓、小麦、鸡蛋和牛奶计量可信。
16. As a 玩家, I want 制作完成的蛋糕进入背包, so that 我可以稍后上架。
17. As a 玩家, I want 制作本身不产生金币或玩家经验, so that 收益只来自售出。
18. As a 玩家, I want 两个蛋糕架从蛋糕店一级起全部可用, so that 不需要逐个解锁架子。
19. As a 玩家, I want 点击地图上的任一蛋糕架打开统一菜单并选中对应槽位, so that 地图操作直观。
20. As a 玩家, I want 两个蛋糕架可以上架不同蛋糕, so that 我可以同时经营多种成品。
21. As a 玩家, I want 两个蛋糕架也可以分别上架同一种蛋糕, so that 我能集中销售热门成品。
22. As a 玩家, I want 每个蛋糕架批次独立计时和结算, so that 一个架子的操作不影响另一个。
23. As a 玩家, I want 每批只上架同一种蛋糕, so that 库存和收益容易理解。
24. As a 玩家, I want 每批至少上架一份, so that 不会创建空批次。
25. As a 玩家, I want 单架上架上限随蛋糕店等级从八份成长到十八份, so that 装修能提高经营容量。
26. As a 玩家, I want 上架数量不能超过背包库存或等级上限, so that 服务端保持权威。
27. As a 玩家, I want 售卖中的蛋糕架不能补货或换品, so that 批次快照保持稳定。
28. As a 玩家, I want 每份蛋糕经过完整销售间隔后才售出, so that 倒计时可预测。
29. As a 玩家, I want 一级蛋糕店默认每八分钟售出一份, so that 蛋糕销售比饮品更慢。
30. As a 玩家, I want 三、五、七、九级每次把销售间隔缩短三十秒, so that 装修可以逐步提速。
31. As a 玩家, I want 十级蛋糕店每六分钟售出一份, so that 满级收益明显。
32. As a 玩家, I want 离线期间蛋糕架继续售卖, so that 无需一直保持页面打开。
33. As a 玩家, I want 售出数量最多等于本批上架数量, so that 离线时间再长也不会超卖。
34. As a 玩家, I want 已上架批次不受后台调价或调速影响, so that 已看到的收益和倒计时保持可信。
35. As a 玩家, I want 售罄蛋糕架显示可收取状态, so that 我知道收益尚未到账。
36. As a 玩家, I want 收取售罄批次的金币和玩家经验, so that 蛋糕销售推动经济与小岛成长。
37. As a 玩家, I want 未售罄时可以下架, so that 我能调整经营计划。
38. As a 玩家, I want 下架时未售蛋糕退回背包, so that 库存不会丢失。
39. As a 玩家, I want 下架时只结算已售部分, so that 不会获得未售库存收益。
40. As a 玩家, I want 重复或并发收取、下架不能重复发钱或退货, so that 资产安全。
41. As a 玩家, I want 蛋糕店菜单显示两个架子的空闲、销售中和售罄状态, so that 我能统一管理。
42. As a 玩家, I want 地图上的空架、蛋糕和金币提示有不同视觉状态, so that 无需打开菜单也能判断情况。
43. As a 设计人员, I want 两个蛋糕架的坐标、图片、锚点、绘制尺寸和碰撞范围可配置, so that 替换美术资源时无需改业务逻辑。
44. As a 设计人员, I want 调整配置后新批次采用新值而旧批次保持快照, so that 运营调整不会破坏玩家承诺。
45. As a 维护人员, I want 蛋糕店等级、配方、材料和蛋糕架配置可审计, so that 后台管理功能以后可以安全建设。

## Implementation Decisions

- Demo2.10 依赖 Demo2.7 的小岛等级和玩家经验、Demo2.8 的作物与配方资格、Demo2.9 的牛奶和鸡蛋库存。
- 蛋糕店是独立金币装修建筑，没有独立经验；小岛等级只提供购买或升级资格。
- 蛋糕店一级需要小岛八级和 5,000 金币；二至十级依次要求小岛九至十七级，金币依次为 8,000、12,000、17,000、23,000、30,000、38,000、47,000、58,000、70,000。
- 小岛八级赠送草莓蛋糕配方；一级蛋糕店开放蛋糕制作能力。二至十级分别固定解锁胡萝卜、橙香、苹果、蓝莓、柠檬、西瓜、苹果胡萝卜、缤纷水果和豪华水果蛋糕。
- 店铺升级配方与小岛等级赠送配方分开记录，固定、幂等、不随机，也不进入提前购买渠道。
- 蛋糕制作和背包扣增必须处于同一事务，并以 JWT 身份为唯一玩家来源。
- 两个蛋糕架使用稳定且唯一的槽位编号；同一槽位最多存在一个未关闭批次，关闭批次保留历史。
- 单架上限按一至十级配置为 8、9、10、11、12、14、15、16、17、18 份。
- 单份销售间隔按一至十级配置为 480、480、450、450、420、420、390、390、360、360 秒。
- 批次上架时保存蛋糕、数量、单份金币、单份玩家经验和单份销售间隔快照。
- 销售不创建逐玩家后台定时任务；读取、下架和收取等公共操作按服务器时间惰性补算。
- 第一份蛋糕必须经过完整快照间隔才售出；售出数量为经过时间除以间隔向下取整，并受批次数量限制。
- 收取和下架使用事务与条件更新保证重复、并发请求幂等。
- 蛋糕架地图布局来自地图配置；两个架子互不重叠、不遮挡蛋糕店入口，并具有独立点击范围。
- 客户端沿用现有父页面与世界地图之间的消息通信，不读取跨域 iframe 的 location。

## Testing Decisions

- 测试只验证 JWT HTTP、持久化事务结果和完整页面可见行为，不测试私有方法或内部调用次数。
- 主要服务端接缝为认证后的蛋糕店 HTTP API：读取店铺、装修、制作、读取架子、上架、下架和收取。
- 时间仅在系统边界可控，用上架后推进服务器时间的场景验证在线与离线销售。
- 数据库测试使用真实测试数据库和约束，覆盖玩家隔离、稳定槽位、活动批次唯一性、快照、幂等与并发。
- 客户端接缝为完整页面和地图消息：点击两个蛋糕架、选择槽位、制作、上架、下架、收取以及三种地图状态。
- 快照测试必须包含上架后修改金币、经验或间隔配置，验证旧批次不变而新批次使用新配置。
- 参考现有饮品店 JWT HTTP 测试、订单履约事务测试、吧台离线销售测试和页面脚本回归测试。

## Out of Scope

- 不建设独立运营后台页面或后台写接口。
- 不新增第三个蛋糕架，也不通过装修增加架子数量。
- 不实现顾客到蛋糕店排队点单、蛋糕满意度或蛋糕店每日礼品。
- 不引入会消耗的种子、仓库容量、原料过期或自动补货。
- 不实现小岛十八级以后、蛋糕店十一级以后或新的畜牧动物。
- 不修改 Demo2.7–2.9 已确定的经验、作物和畜牧规则。
