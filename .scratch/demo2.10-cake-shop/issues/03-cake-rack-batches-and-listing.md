# 03 — 建立两个蛋糕架并支持上架

**What to build:** 为每位玩家建立两个稳定蛋糕架和可保留历史的销售批次，按蛋糕店等级限制单架上架数量，并在上架时锁定收益和销售间隔。

**Blocked by:** 01, 02

**Status:** resolved

## Acceptance criteria

- [ ] 每位玩家始终拥有编号稳定且唯一的两个蛋糕架
- [ ] 两个架子从蛋糕店一级起全部可用
- [ ] 同一架子最多一个未关闭批次，不同架子可上架相同蛋糕
- [ ] 每批只能上架一种蛋糕且至少 1 份
- [ ] 上架数量不能超过背包库存或当前等级单架上限
- [ ] 一级至十级上限严格使用 8、9、10、11、12、14、15、16、17、18
- [ ] 上架原子扣减背包蛋糕并创建批次
- [ ] 批次保存上架数量、已售数量、状态和关键时间
- [ ] 批次保存单份金币、玩家经验和销售间隔快照
- [ ] 已售卖中的架子不能补货或换品
- [ ] JWT 读取只返回当前玩家两个架子的权威状态
- [ ] 状态足以表达空闲、销售中和售罄待收取
- [ ] 初始化和迁移幂等，关闭批次保留历史
- [ ] HTTP 测试覆盖玩家隔离、数量边界、快照和活动批次唯一性
