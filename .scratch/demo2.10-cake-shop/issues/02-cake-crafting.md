# 02 — 完成蛋糕制作与背包事务

**What to build:** 让玩家通过蛋糕店制作台选择已拥有且当前店铺允许制作的蛋糕配方和数量，按配置扣除作物、牛奶和鸡蛋，并把成品蛋糕按份存入背包。

**Blocked by:** 01

**Status:** resolved

## Acceptance criteria

- [ ] JWT 制作接口只操作当前玩家
- [ ] 配方资格、蛋糕店制作能力和配方启用状态都必须满足
- [ ] 已获得但店铺条件不足的配方保持可见并返回明确缺少条件
- [ ] 制作数量默认为 1，必须为正数且不能超过材料可制作数量
- [ ] 草莓蛋糕及店铺升级蛋糕严格使用配置材料
- [ ] 作物、牛奶和鸡蛋扣减与蛋糕入包处于同一事务
- [ ] 任一材料不足时不扣除任何库存
- [ ] 单纯制作不产生金币或玩家经验
- [ ] 重复提交与并发制作不能导致负库存
- [ ] 客户端展示配方、材料库存、剩余数量和制作上限
- [ ] 无库存时数量与加减按钮正确禁用
- [ ] 服务端测试覆盖多材料、数量边界、事务回滚和并发安全
- [ ] 客户端 TypeScript 与页面脚本测试覆盖制作交互
