# 05 — 完成室外蛋糕架地图与经营界面

**What to build:** 在蛋糕店小屋外绘制两个可点击蛋糕架，通过统一菜单展示状态并完成制作、上架、下架和收取流程；位置与图片相关参数全部来自地图配置。

**Blocked by:** 02, 03, 04

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 地图显示两个互不重叠且不遮挡蛋糕店入口的蛋糕架
- [ ] 两个槽位坐标、图片、锚点、绘制尺寸和碰撞范围来自配置
- [ ] 点击任一架子打开统一菜单并自动选中正确槽位
- [ ] 空架、销售中和售罄分别显示空托盘、蛋糕和金币提示
- [ ] 菜单同时显示两个架子的权威状态
- [ ] 空架可以从背包选择蛋糕和 1 至等级上限的数量
- [ ] 上架数量不能超过库存或等级上限
- [ ] 销售中显示已售、剩余、待收收益和下一份倒计时
- [ ] 未售罄架子提供确认后的下架操作
- [ ] 售罄架子提供收取操作并刷新金币、经验、背包和地图状态
- [ ] 两个架子可以同时上架同一种或不同蛋糕
- [ ] 父页面与世界地图使用消息通信，不读取 iframe location
- [ ] 替换图片后的配置注释说明坐标、锚点和碰撞调整方法
- [ ] 客户端 TypeScript、页面脚本和真实页面验证覆盖完整经营路径
