# 01 — 建立蛋糕店装修等级与固定配方资格

**What to build:** 建立蛋糕店玩家状态、一级至十级装修配置、金币与小岛等级门槛，以及草莓蛋糕和店铺升级固定配方资格。提供 JWT 权威读取与逐级装修接口。

**Blocked by:** None — requires Demo2.7–2.9 prerequisite specs to be resolved before implementation

**Status:** resolved

## Acceptance criteria

- [ ] 每位玩家拥有唯一蛋糕店状态，未解锁、一级至十级状态可区分
- [ ] 小岛八级且支付 5,000 金币才能首次解锁一级蛋糕店
- [ ] 二至十级的小岛门槛、金币和固定奖励严格使用配置
- [ ] 只能逐级装修，等级不足、金币不足或跳级请求不改变任何状态
- [ ] 小岛八级赠送的草莓蛋糕配方与一级制作能力正确组合
- [ ] 二至十级店铺配方固定、幂等、不随机、不进入提前购买渠道
- [ ] JWT 是玩家身份唯一来源，不能通过请求体操作其他玩家
- [ ] 装修扣金币、升等级和发配方处于同一事务
- [ ] 重复或并发装修不会重复扣金币或重复发配方
- [ ] 读取接口返回当前等级、下一等级门槛、金币、奖励预览和制作能力
- [ ] 数据迁移兼容已有玩家并可幂等执行
- [ ] JWT HTTP 测试覆盖成功、等级不足、金币不足、跳级、重复和玩家隔离
