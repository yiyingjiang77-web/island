# 04 — 完成蛋糕架离线销售、下架与收取

**What to build:** 按销售间隔快照和服务器时间惰性补算蛋糕架销量，支持提前下架退回未售蛋糕并结算已售收益，以及售罄后安全收取金币和玩家经验。

**Blocked by:** 03

**Status:** resolved

## Acceptance criteria

- [ ] 第一份蛋糕必须经过完整销售间隔才售出
- [ ] 各等级默认间隔严格使用 480、480、450、450、420、420、390、390、360、360 秒
- [ ] 在线和离线读取使用同一补算规则
- [ ] 售出数量按经过时间向下取整且不超过上架数量
- [ ] 全部售出后进入售罄待收取状态并继续占用架子
- [ ] 下架只允许当前玩家操作
- [ ] 下架退回未售蛋糕并结算已售金币和经验
- [ ] 售罄收取结算全部快照收益并清空当前架子
- [ ] 金币和经验结算可触发小岛连续升级
- [ ] 重复或并发读取、下架和收取不会超卖、重复退货或重复发放收益
- [ ] 上架后修改收益或间隔配置不改变旧批次
- [ ] 新批次采用修改后的配置
- [ ] 时间边界测试覆盖不足一份、恰好一份、多份、长时间离线和上限
- [ ] 真实数据库事务测试覆盖回滚、条件更新和玩家隔离
