# 05 — 惰性结算在线与离线鸡蛋生产

**What to build:** 使用服务器时间和当前生产周期快照惰性补算鸡蛋，支持鸡数量、额外鸡蛋和生产周期随等级变化，并保证离线、多周期和并发结算安全。

**Blocked by:** 04 — 解锁并升级鸡舍

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 一级鸡舍解锁后 599 秒没有周期鸡蛋到账，满 600 秒结算第一轮一个鸡蛋
- [ ] 每轮总鸡蛋等于该周期鸡数量加额外鸡蛋快照
- [ ] 鸡蛋按个原子写入当前玩家背包
- [ ] 四级生产周期使用九分三十秒，七级每轮在五只鸡基础上额外产一个鸡蛋
- [ ] 十级八只鸡每轮产九个鸡蛋，动物数不超过八只硬上限
- [ ] 长时间离线后一次 JWT 畜牧读取补齐所有完整生产周期
- [ ] 未完成周期的已经过时间和剩余时间在刷新后保持单调，不会重置
- [ ] 多次读取同一时间点不会重复发放同一周期鸡蛋
- [ ] 鸡舍升级前先结算截至升级时刻已经完成的周期
- [ ] 周期中途升级时当前周期继续使用旧周期、鸡数量和额外产量快照
- [ ] 升级后的下一周期使用新等级配置
- [ ] 配置在周期中途变更时当前周期不变，后续周期按生效版本计算
- [ ] 牛棚和鸡舍可跨不同周期独立补算，任一失败不会产生另一建筑的重复结算
- [ ] 重复或并发读取、升级至多结算每个完整周期一次
- [ ] 使用可控服务器时钟的 JWT HTTP 测试覆盖 599/600 秒、570 秒周期、额外鸡蛋、多周期、快照、并发与背包权威读取
