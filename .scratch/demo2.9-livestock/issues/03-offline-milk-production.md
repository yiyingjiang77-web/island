# 03 — 惰性结算在线与离线牛奶生产

**What to build:** 使用服务器时间和当前生产周期快照惰性补算奶牛产出的牛奶，覆盖多周期离线、周期中途升级或配置变化、背包原子入库和并发安全。

**Blocked by:** 02 — 解锁并升级牛棚

**Status:** resolved

## Acceptance criteria

- [ ] 一级牛棚解锁后 599 秒没有周期牛奶到账，满 600 秒结算第一轮
- [ ] 每轮总牛奶等于该周期奶牛数量乘以单头产量快照
- [ ] 牛奶按份原子写入当前玩家背包
- [ ] 长时间离线后一次 JWT 畜牧读取补齐所有完整生产周期
- [ ] 未完成周期的已经过时间和剩余时间在刷新后保持单调，不会重置
- [ ] 多次读取同一时间点不会重复发放同一周期牛奶
- [ ] 牛棚升级前先结算截至升级时刻已经完成的周期
- [ ] 周期中途升级时当前周期继续使用旧周期、奶牛数和产量快照
- [ ] 升级后的下一周期使用新等级的奶牛数和产量配置
- [ ] 配置在周期中途变更时当前周期不变，后续周期按生效版本计算
- [ ] 牛棚和鸡舍生产边界互相独立，读取牛棚不会重置鸡舍状态
- [ ] 重复或并发读取、升级至多结算每个完整周期一次
- [ ] 结算失败时生产边界和背包增量一同回滚
- [ ] 服务端返回下一次牛奶产出时间、剩余秒数和每轮预计产量
- [ ] 使用可控服务器时钟的 JWT HTTP 测试覆盖 599/600 秒、多周期、快照、配置切换、并发与背包权威读取
