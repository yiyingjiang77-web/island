# 04 — 解锁并升级鸡舍

**What to build:** 提供鸡舍首次金币解锁和一级至十级配置化逐级升级。首次解锁原子赠送一只鸡和五个鸡蛋；升级应用小岛门槛、金币、容量、自动新增鸡、生产周期和额外鸡蛋配置。

**Blocked by:** 03 — 惰性结算在线与离线牛奶生产

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 小岛八级以下不能解锁鸡舍，失败不扣金币或发奖励
- [ ] 小岛八级只获得购买资格，不会自动解锁或扣金币
- [ ] 首次解锁准确扣除 3,000 金币并把鸡舍设为一级
- [ ] 首次解锁在同一事务内赠送一只鸡和五个鸡蛋到当前玩家背包
- [ ] 鸡蛋按“个”保存，不进行桶或份数换算
- [ ] 首次奖励不计为生产周期产出，第一轮从解锁时刻开始等待完整周期
- [ ] 鸡舍只能逐级升级，跳级、小岛等级不足或金币不足均不改变状态
- [ ] 二至十级严格采用已确认的小岛门槛和金币配置
- [ ] 升级成功原子扣金币、提升等级并在配置等级自动新增鸡
- [ ] 四级和七级等不新增鸡的等级不会错误赠送动物
- [ ] 鸡舍鸡数量永远不超过当前容量或八只硬上限
- [ ] 重复或并发首次解锁至多成功一次，不重复扣金币、发鸡或发鸡蛋
- [ ] 重复或并发升级不会跨级、重复扣金币或重复赠送鸡
- [ ] JWT 是玩家身份唯一来源，不能解锁或升级其他玩家鸡舍
- [ ] JWT HTTP 和真实数据库测试覆盖首次奖励、逐级门槛、金币、容量、幂等、并发和玩家隔离
