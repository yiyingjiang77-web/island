# 06 — 建立牛棚与鸡舍客户端交互

**What to build:** 在现有小岛客户端提供牛棚与鸡舍管理入口，展示购买资格、首次奖励、当前动物、生产倒计时、每轮产量和升级预览，并在操作后刷新金币与背包。

**Blocked by:** 03 — 惰性结算在线与离线牛奶生产; 05 — 惰性结算在线与离线鸡蛋生产

**Status:** resolved

## Acceptance criteria

- [ ] 客户端提供牛棚和鸡舍的明确入口，并能区分未达到等级、可购买、生产中和可升级状态
- [ ] 牛棚未解锁时展示小岛五级门槛、配置金币、一头奶牛和十份牛奶首次奖励
- [ ] 鸡舍未解锁时展示小岛八级、3,000 金币、一只鸡和五个鸡蛋首次奖励
- [ ] 条件不足时按钮禁用或服务端拒绝结果可见，且不会显示虚假的成功状态
- [ ] 解锁前有清楚确认，成功后刷新建筑、玩家金币和背包
- [ ] 已解锁建筑展示等级、动物数量/容量、当前每轮产量、下一次产出时间和倒计时
- [ ] 升级面板展示目标等级所需小岛等级、金币、动物与生产变化
- [ ] 牛棚未配置或未启用的下一等级显示暂未开放，而不是允许无效升级
- [ ] 鸡舍二至十级使用服务端返回配置，不在页面硬编码门槛或产量
- [ ] 倒计时根据服务端权威边界显示，刷新页面不会从完整周期重新开始
- [ ] 读取触发离线补算后，牛奶和鸡蛋背包数量同步刷新
- [ ] 重复点击期间阻止重复提交，并以服务端权威结果收敛
- [ ] 牛奶按份、鸡蛋按个显示，不向玩家展示可消耗的“牛奶桶”
- [ ] 页面不实现蛋糕制作、蛋糕店入口或蛋糕架交互
- [ ] 客户端 TypeScript、页面脚本解析和完整页面交互回归测试覆盖解锁、升级、倒计时、离线入包和条件不足
