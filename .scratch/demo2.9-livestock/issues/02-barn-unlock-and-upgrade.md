# 02 — 解锁并升级牛棚

**What to build:** 提供牛棚首次金币解锁与配置化逐级升级能力。首次解锁原子赠送一头奶牛和十份牛奶；升级按配置校验小岛等级、金币、容量和自动新增奶牛。

**Blocked by:** 01 — 建立畜牧配置、玩家状态与 JWT 读取接缝

**Status:** resolved

## Acceptance criteria

- [ ] 小岛五级以下不能解锁牛棚，失败不扣金币或发奖励
- [ ] 小岛五级只获得购买资格，不会自动解锁或扣金币
- [ ] 首次解锁使用启用的一级牛棚金币配置并把牛棚设为一级
- [ ] 首次解锁在同一事务内赠送一头奶牛和十份牛奶到当前玩家背包
- [ ] 十份牛奶按“份”保存，不创建可消耗的“桶”库存
- [ ] 首次奖励不计为生产周期产出，第一轮从解锁时刻开始等待完整周期
- [ ] 牛棚只能逐级升级，目标配置未启用、跳级、小岛等级不足或金币不足均不改变状态
- [ ] 升级成功原子扣金币、提升等级并按配置自动新增奶牛
- [ ] 二、三、五、八、十级的自动新增奶牛与容量配置可正确执行
- [ ] 牛棚奶牛数量永远不超过当前容量或八头硬上限
- [ ] 重复或并发首次解锁至多成功一次，不重复扣金币、发奶牛或发牛奶
- [ ] 重复或并发升级不会跨级、重复扣金币或重复赠送奶牛
- [ ] JWT 是玩家身份唯一来源，不能解锁或升级其他玩家牛棚
- [ ] 成功和失败后 JWT 读取返回权威等级、金币、奶牛数、下一等级预览与生产边界
- [ ] JWT HTTP 和真实数据库测试覆盖门槛、首次奖励、逐级升级、未启用配置、幂等、并发和玩家隔离
