# 03 — 通过种子商店购买额外永久种植权

**What to build:** 建立配置驱动的种子商店读取与金币购买行为。商店只出售永久作物种植权，不出售消耗型种子；客户端展示商品条件、已拥有状态和购买结果。

**Blocked by:** 01 — 建立十种作物目录、十级配置与永久种植权

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 种子商店只返回启用且允许永久获得的金币商店来源
- [ ] 每个商品返回作物名称、价格、所需小岛等级、是否拥有和是否可购买
- [ ] 商品与价格、等级门槛从配置读取，不在客户端写死
- [ ] 与前十级固定等级赠送冲突的商店来源不能同时启用
- [ ] 玩家达到门槛且金币足够时可购买作物一级永久种植权
- [ ] 购买后该作物可无限次种植且不产生可消耗种子数量
- [ ] 等级不足、金币不足、商品停用或作物不可永久获得时不改变资产
- [ ] 已经永久拥有的作物不能再次购买或重复扣金币
- [ ] 商店扣金币和永久种植权创建处于同一事务
- [ ] 重复或并发购买最多一次成功
- [ ] JWT 是玩家身份唯一来源，不能替其他玩家购买
- [ ] 白菜、土豆、辣椒和玉米可继续由配置用于未来商店、任务或等级来源
- [ ] 月光莓不出现在永久种子商店
- [ ] 客户端明确使用“永久种植权”文案并展示锁定、可购买和已拥有状态
- [ ] 购买成功后刷新金币、种植权、种植选择器和商品状态
- [ ] 真实 JWT HTTP 测试覆盖目录、成功购买、所有失败分支、玩家隔离及并发
