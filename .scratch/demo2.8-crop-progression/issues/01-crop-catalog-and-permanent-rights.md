# 01 — 建立十种作物目录、十级配置与永久种植权

**What to build:** 扩展作物目录为前十级小岛固定获得的十种常规作物，为每种作物建立一级至十级独立数值配置，并接入 Demo2.7 的小岛升级奖励，使永久作物种植权可通过 JWT 权威初始化数据读取。

**Blocked by:** None — requires Demo2.7 island progression to be resolved before implementation

**Status:** resolved

## Acceptance criteria

- [ ] 前十级固定作物严格为草莓、胡萝卜、橙子、番茄、蓝莓、苹果、西瓜、小麦、柠檬、黄瓜
- [ ] 十种作物各有一级至十级共一百条独立等级配置
- [ ] 一级成长时间、产量和收获经验与父规格一致
- [ ] 二至十级成长时间、产量、经验和升级金币按统一模板正确生成并可逐项覆盖
- [ ] 所有十级产量均不超过八份，成长时间不低于三十秒
- [ ] 玩家取得永久种植权时作物固定从一级开始
- [ ] 小岛逐级奖励调用可幂等发放对应作物种植权
- [ ] 新玩家永久获得草莓，已有高等级玩家可安全补齐遗漏的逐级作物奖励
- [ ] 作物种植权不进入背包且不会因种植而消耗
- [ ] JWT 初始化读取返回作物目录、等级配置、当前玩家永久种植权和来源
- [ ] 不把月光莓改为永久作物，不删除白菜、土豆、辣椒或玉米既有数据
- [ ] 数据迁移兼容已有作物等级，不回退、不重复创建种植权且可幂等执行
- [ ] 真实 JWT HTTP 测试覆盖新玩家、已有玩家补发、跨多级奖励、玩家隔离和一百条配置契约
