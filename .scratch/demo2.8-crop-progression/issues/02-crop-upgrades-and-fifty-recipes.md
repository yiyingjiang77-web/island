# 02 — 作物逐级升级并发放五十条固定配方

**What to build:** 提供 JWT 作物升级行为，按配置逐级扣除金币、提升作物等级，并在二、三、五、七、十级幂等发放父规格确定的五十条永久配方。客户端展示十级成长、下一等级数值、金币和奖励条件。

**Blocked by:** 01 — 建立十种作物目录、十级配置与永久种植权

**Status:** resolved

## Acceptance criteria

- [ ] 只有永久拥有且允许升级的作物可以执行升级
- [ ] 作物只能从当前等级升到下一等级，不能跳级或超过十级
- [ ] 升级金币严格读取目标等级配置
- [ ] 金币不足、配置缺失、作物未拥有或达到满级时不改变任何资产
- [ ] 金币扣除、等级提升和奖励发放处于同一事务
- [ ] 二、三、五、七、十级固定发放对应奖励，其余等级不发配方
- [ ] 五十条奖励名称、制作入口和材料严格使用父规格配置基线
- [ ] 每条奖励配方材料都包含触发升级的作物
- [ ] 发放配方时不检查其他作物种植权、材料库存、牛奶、鸡蛋或制作建筑
- [ ] 暂不可制作配方保持永久拥有并返回缺少材料或未来入口条件
- [ ] 蛋糕店配方不在本任务中获得蛋糕制作能力
- [ ] “橙果酸奶冻”使用牛奶且不新增酸奶材料
- [ ] 重复或并发升级最多成功一次，不重复扣金币或发配方
- [ ] JWT 是玩家身份唯一来源，伪造请求体玩家标识无效
- [ ] 页面展示当前等级、一至十级预览、奖励节点、金币缺口和升级结果
- [ ] 操作成功后页面刷新金币、作物等级与配方资格
- [ ] 真实 JWT HTTP 测试覆盖普通升级、五个奖励节点、满级、失败回滚、玩家隔离和并发
