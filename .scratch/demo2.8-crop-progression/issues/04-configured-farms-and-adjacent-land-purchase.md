# 04 — 配置四个农田区块并按相邻规则购买六十四格土地

**What to build:** 统一四个 4×4 农田区块及六十四格土地配置，保留唯一免费初始格，并通过 JWT 土地接口执行小岛等级门槛、金币扣除和上下左右相邻购买。

**Blocked by:** 01 — 建立十种作物目录、十级配置与永久种植权

**Status:** resolved

## Acceptance criteria

- [ ] 农田 A、B、C、D 各包含十六个唯一局部坐标土地格，共六十四格
- [ ] 四区小岛等级门槛依次为一、三、五、八级
- [ ] 四区总购买金币依次为 1,300、2,150、4,300、7,500，合计 15,250
- [ ] 全局只有农田 A 的一个免费初始格，新玩家初始化时永久获得
- [ ] 玩家达到门槛只获得购买资格，不自动获得整个区块
- [ ] 除免费初始格外，目标格必须与同区块至少一个已购格上下左右相邻
- [ ] 只有对角线相邻、跨区块相邻或隔空土地均不能购买
- [ ] 等级不足、金币不足、土地停用、已购或不相邻时不改变任何状态
- [ ] 购买扣金币与创建玩家土地处于同一事务
- [ ] 重复或并发购买同一格最多一次成功
- [ ] 已购土地不因配置调价、门槛变化、坐标变化或停用而被回收
- [ ] JWT 是玩家身份唯一来源，不能购买其他玩家的土地
- [ ] 服务端读取返回足以表达锁定、待购买和已购状态的六十四格权威视图
- [ ] 地图区块坐标、尺寸、显示顺序和启用状态来自 FarmConfig，土地局部坐标来自权威配置
- [ ] 客户端展示准确等级、金币和不相邻原因，并在购买后刷新地图与余额
- [ ] 数据迁移保持稳定土地编码并兼容已有已购土地
- [ ] 真实 JWT HTTP 测试覆盖四区门槛、价格总和、相邻边界、失败回滚、玩家隔离和并发
