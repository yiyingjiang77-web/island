# Demo2.8 作物·花卉·蜂蜜系统 + 农田扩建

**Status:** resolved  
**重写日期:** 2026-08-01（基于 Demo3.0 设计重写原 Demo2.8）

## Problem Statement

玩家已在 Demo2.7 获得岛屿等级体系和累计经验，但作物体系仍沿用旧配置——白菜、土豆、辣椒、玉米四种无配方关联的作物需要移除，作物只有三级且缺少完整成长空间，玩家无法获得花卉和蜂蜜这两种连接饮品与甜品经济的关键材料。

## Solution

基于 Demo3.0 经济重平衡与无限等级设计，重建完整的种植经营循环：

**核心改动 vs 原 Demo2.8：**
- 作物从 10 种调整为 11 种基础作物（删白菜/土豆/辣椒/玉米），全部通过岛屿等级升级赠送获得（单一渠道，商店不卖基础作物种子）
- 移除"作物升级赠送配方"机制——配方改为独立获取渠道（岛屿等级奖励 + 兑换商店），作物升级仅提供纯数值收益
- 新增 8 种可食用花卉（7 金币 + 1 钻石樱花），全部通过商店购买种子，花卉 Lv1-10 可升级
- 新增蜂蜜系统：单一蜂蜜物品，蜂箱自动采集已成熟花朵产蜜，产蜜公式 `floor(Σ(花数量 × 系数 × 等级倍率))`
- 保留原土地扩建机制（4 区块 × 16 格 = 64 格，相邻购买规则）
- 保留原种植收获机制（等级快照、浇水启动倒计时、产量封顶 8）

**约束规则：**
- 只能逐级升级，不能跳级
- 产量上限封顶 8 份（产量 = 一级产量 + 增量，max=8）

## 第三章：蜂蜜系统

### 3.1 蜂蜜基础规则

- 蜂蜜为**单一物品**，不分种类，编号 `honey`
- 产蜜公式：每周期 `floor(Σ(已成熟花朵数量 × 蜂蜜系数 × 等级倍率))`
- 产蜜周期：2 小时（7,200 秒）
- 金币花系数 = 1，钻石花系数 = 2
- 等级倍率公式：`min(1 + 0.4 × (level - 1)^0.85, 5.0)`，当前 Lv1-10 上限为 Lv10=3.63

| 花等级 | 等级倍率 | 金币花贡献/朵 | 钻石花贡献/朵 |
|--------|---------|-------------|-------------|
| Lv1 | 1.00 | 1.0 | 2.0 |
| Lv2 | 1.40 | 1.4 | 2.8 |
| Lv3 | 1.72 | 1.7 | 3.4 |
| Lv5 | 2.31 | 2.3 | 4.6 |
| Lv8 | 3.12 | 3.1 | 6.2 |
| Lv10 | 3.63 | 3.6 | 7.3 |
| Lv16 | 5.00（封顶） | 5.0 | 10.0 |

**举例：** 种了 5 朵玫瑰(Lv5 金币) + 3 朵樱花(Lv3 钻石) + 2 朵菊花(Lv1 金币)：
```
产蜜 = 5×1×2.31 + 3×2×1.72 + 2×1×1.00
     = 11.55 + 10.32 + 2.00
     = 23.87 → 23 蜂蜜/周期
```

### 3.2 蜂箱

- 蜂箱是建筑类物品，在商店金币购买
- 蜂箱不扫描特定范围——**统计玩家所有已成熟花卉**产出蜂蜜
- 蜂箱数量只决定存储上限，最多 3 个

| 蜂箱数量 | 存储上限 | 金币价格 |
|---------|---------|---------|
| 1 个 | 20 | 1,000 |
| 2 个 | 40 | 2,000 |
| 3 个 | 60 | 3,000 |

- 存储满后**停止产蜜**（不溢出不丢弃），玩家收取后继续生产
- 没有花（零已成熟花卉）时**不产蜜**
- 蜂箱产蜜使用服务器时间惰性结算（与畜牧离线生产同理）

### 3.3 蜂蜜用途

- 作为多种配方的基础材料（饮品、甜品均需要）
- 可直接卖给商店（背包出售价：15 金币/份）
- 可赠送 NPC（小蜜蜂群、花姨等 NPC 最爱的礼物）

- 四个 4×4 农田区块：A、B、C、D，共 64 格土地
- 玩家初始化时获得农田 A 的**唯一免费初始格**

|------|------------|---------|
| 农田 A | 岛Lv1（初始化获得首格） | 1,300 金 |
| 农田 B | 岛Lv3 | 2,150 金 |
| 农田 C | 岛Lv5 | 4,300 金 |
| 农田 D | 岛Lv8 | 7,500 金 |
| **合计** | | **15,250 金** |

### 4.2 购买规则

- 只有与同区块已购土地上下左右相邻的格子可以购买
- 对角线、跨区块、隔空土地不可购买
- 达到等级门槛获得购买资格，不自动获得整区土地
- 已购土地永久保留，不因配置变更被回收

## 第五章：种植与收获

（保留原 Demo2.8 设计，与现有种植流程一致）

### 5.1 种植流程

- 点击空地 → 选择已拥有作物/花卉 → 种下
- 种植不消耗种子/种植权数量（种植权永久、非消耗型）
- 种植时保存本轮快照：作物等级、成长时间、产量、收获经验、权限类型
- 浇水后以服务器时间开始成熟倒计时

### 5.2 收获规则

- 只有经过完整成长时间（浇水后）才能收获
- 产量 = 快照产量，封顶 8 份
- 收获经验 = 快照经验，不乘以产量份数
- 收获清空土地、背包增加、经验结算、触发岛屿升级处于同一事务
- 中途升级作物不影响已种下的本轮快照
- 重复或并发收获最多成功一次
