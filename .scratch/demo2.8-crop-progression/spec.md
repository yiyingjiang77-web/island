# Demo2.8 作物成长、种子商店与农田扩建

**Status:** ready-for-agent

## Problem Statement

当前玩家虽然已经可以在土地上种植和收获草莓，但作物成长仍停留在少量旧配置：前十级小岛缺少逐级获得的十种常规作物，作物等级没有完整延伸到十级，升级也没有形成固定配方奖励。玩家无法通过种子商店取得额外永久种植权，四个农田区块的六十四格土地也缺少统一的配置化购买与相邻扩建体验。

## Solution

在 Demo2.7 的小岛等级与玩家经验之上建立完整的作物成长循环。玩家随小岛等级获得草莓、胡萝卜、橙子、番茄、蓝莓、苹果、西瓜、小麦、柠檬和黄瓜的永久作物种植权；每种作物均可花费金币从一级逐级升到十级，并在二、三、五、七、十级固定获得与该作物相关的永久配方。种子商店继续出售配置指定的额外永久种植权，不引入消耗型种子。

地图保留四个 4×4 农田区块，共六十四格土地。玩家获得唯一免费初始土地，达到小岛等级门槛后再按配置花费金币、沿上下左右相邻土地逐格扩建。种植时锁定本轮成长时间、产量和收获经验，收获产量永远不超过八份。玩家通过带 JWT 的农田 HTTP 行为完成购买、种植、浇水、收获、作物升级和种子商店购买，并在完整页面中查看种植权、作物等级、升级奖励、材料来源和土地状态。

## User Stories

1. As a 玩家, I want 初始永久拥有草莓种植权, so that 我可以立即开始种植。
2. As a 玩家, I want 小岛每升一级固定获得一种新作物种植权, so that 成长奖励清晰可预期。
3. As a 玩家, I want 小岛一至十级依次获得十种指定作物, so that 我不会得到随机或重复的主线作物。
4. As a 玩家, I want 作物种植权永久有效, so that 每次种植不会消耗种子数量。
5. As a 玩家, I want 只在种植选择器中看到自己永久拥有或仍有效的临时作物, so that 不能越权种植。
6. As a 玩家, I want 已获得作物从一级开始, so that 每种作物都有独立成长空间。
7. As a 玩家, I want 每种常规作物都可以升到十级, so that 长期投入有明确上限。
8. As a 玩家, I want 作物只能逐级升级, so that 不能跳过金币成本或奖励节点。
9. As a 玩家, I want 升级前看到下一等级的成长时间、产量、经验、金币和配方奖励, so that 我能规划资源。
10. As a 玩家, I want 金币不足时看到准确缺口, so that 升级失败不会让我误以为金币已扣。
11. As a 玩家, I want 达到十级后不能继续升级, so that 配置上限得到服务端保证。
12. As a 玩家, I want 作物升级后新的种植轮次成长更快, so that 升级立即具有可见价值。
13. As a 玩家, I want 作物升级后新的种植轮次可以提高产量, so that 单块土地更有效率。
14. As a 玩家, I want 单次收获最多八份, so that 高等级作物不会无限膨胀经济。
15. As a 玩家, I want 作物升级后新的种植轮次可以提高收获经验, so that 种植继续推动小岛成长。
16. As a 玩家, I want 已经种下的作物保持种植时的等级数值, so that 中途升级不会改变已看到的倒计时和收益。
17. As a 玩家, I want 后台调整作物配置不改变已经种下的一轮, so that 运营调整不会破坏当前承诺。
18. As a 玩家, I want 浇水后才开始成熟倒计时, so that 现有种植流程保持一致。
19. As a 玩家, I want 未成熟作物不能提前收获, so that 服务端时间是权威来源。
20. As a 玩家, I want 收获后作物按配置数量进入背包, so that 资产结果可核对。
21. As a 玩家, I want 每次收获只结算一次配置经验, so that 经验不会再乘以产量份数。
22. As a 玩家, I want 收获经验可以触发 Demo2.7 的连续小岛升级, so that 种植与全局成长连通。
23. As a 玩家, I want 作物升到二级时固定获得一个相关配方, so that 早期升级有明确奖励。
24. As a 玩家, I want 作物升到三级时固定获得一个相关配方, so that 连续升级仍有目标。
25. As a 玩家, I want 作物升到五级时固定获得一个相关配方, so that 中期成长能扩展经营内容。
26. As a 玩家, I want 作物升到七级时固定获得一个相关配方, so that 高级投入有独特回报。
27. As a 玩家, I want 作物升到十级时固定获得一个相关配方, so that 满级具有终局奖励。
28. As a 玩家, I want 每个升级配方都必须使用触发升级的作物, so that 奖励与我的投入直接相关。
29. As a 玩家, I want 配方奖励固定而非随机, so that 我可以提前规划作物升级路线。
30. As a 玩家, I want 升级配方永久有效且不会重复发放, so that 重试或并发请求不会制造重复资格。

34. As a 玩家, I want 奶制或蛋类配方标明未来材料来源, so that Demo2.8 不需要提前实现畜牧。
35. As a 玩家, I want 打开种子商店查看配置允许购买的额外作物, so that 我能扩展主线等级奖励以外的种植选择。
36. As a 玩家, I want 种子商店明确说明出售的是永久种植权, so that 我不会误以为购买后只可种一次。

38. As a 玩家, I want 花费金币购买配置指定的作物种植权, so that 额外作物有长期获取渠道。
39. As a 玩家, I want 等级不足或金币不足时购买不改变资产, so that 失败操作安全。
40. As a 玩家, I want 已经拥有的作物不能再次购买, so that 不会重复扣费。
41. As a 玩家, I want 种子商店购买与金币扣除处于同一事务, so that 永久种植权和资产始终一致。
42. As a 玩家, I want 首次进入时永久获得农田 A 的一个免费土地格, so that 我无需先赚钱才能种植。
43. As a 玩家, I want 地图上看到四个 4×4 农田区块, so that 土地扩建空间清晰。
44. As a 玩家, I want 小岛一级、三级、五级和八级分别开放四个农田区块的购买资格, so that 土地容量随全局成长展开。
45. As a 玩家, I want 达到等级后仍需逐格花金币购买土地, so that 解锁资格不会自动替我消费或赠送整区土地。
46. As a 玩家, I want 只能购买与同区块已购土地上下左右相邻的土地, so that 农田从已有边界连续扩建。
47. As a 玩家, I want 对角线相邻不算可购买, so that 相邻规则直观一致。
48. As a 玩家, I want 农田 B、C、D 不出现额外免费土地, so that 全局只有一个初始赠送格。
49. As a 玩家, I want 已购土地永久有效, so that 后台调价或改布局不会收回我的资产。
50. As a 玩家, I want 土地购买、种植、浇水和收获都只使用 JWT 身份, so that 不能操作其他玩家的农田。
51. As a 玩家, I want 重复或并发购买同一土地不会重复扣金币, so that 扩建操作安全。
52. As a 玩家, I want 重复或并发收获不会重复获得作物和经验, so that 背包与等级可信。
53. As a 玩家, I want 页面操作后刷新土地、背包、金币、作物等级和配方, so that 所见状态与服务端一致。
54. As a 玩家, I want 点击空地时选择任意已拥有作物, so that 不再默认写死草莓。

60. As a 维护人员, I want 配置迁移可幂等执行并兼容已有玩家, so that 上线不会丢失既有种植权、作物等级或土地。

## Implementation Decisions

- Demo2.8 依赖 Demo2.7 提供小岛等级、玩家经验、连续升级和逐级奖励调用；Demo2.8 负责把作物种植权作为永久、幂等的等级奖励落地。
- 前十级小岛固定作物顺序为：一级草莓、二级胡萝卜、三级橙子、四级番茄、五级蓝莓、六级苹果、七级西瓜、八级小麦、九级柠檬、十级黄瓜。
- 作物种植权不是背包物品，没有可消耗数量；玩家永久拥有后可在任意空土地重复选择该作物。
- 十种常规作物的一级基础数值依次为：草莓 60 秒/2 份/5 经验，胡萝卜 180 秒/3 份/12 经验，橙子 240 秒/3 份/15 经验，番茄 240 秒/3 份/15 经验，蓝莓 300 秒/4 份/18 经验，苹果 360 秒/4 份/22 经验，西瓜 480 秒/3 份/25 经验，小麦 300 秒/5 份/20 经验，柠檬 420 秒/4 份/25 经验，黄瓜 360 秒/4 份/22 经验。
- 每种常规作物均保存一级至十级的独立配置行。初始数据按统一模板生成，后续允许逐项覆盖。
- 二至十级的成长时间比例依次为 95%、90%、85%、80%、75%、70%、65%、60%、50%；四舍五入到秒且最低 30 秒。
- 一级至十级相对一级的产量增量依次为 0、1、1、2、2、3、3、4、4、5，最终使用一级产量加增量并封顶为 8 份。
- 一级至十级的收获经验比例依次为 100%、115%、130%、145%、160%、180%、200%、225%、250%、280%，四舍五入为整数，每次收获只结算一次。
- 二至十级的升级金币倍率依次为 1、2、4、7、11、16、22、29、37。草莓、胡萝卜、橙子、番茄、蓝莓、苹果、西瓜、小麦、柠檬、黄瓜的金币基数依次为 200、400、500、500、600、700、900、800、900、800。
- 作物只能逐级升级。金币扣除、作物等级更新和奖励配方发放位于同一事务；升级请求只根据 JWT 玩家身份定位资产。
- 作物二、三、五、七、十级各配置一个固定永久配方，使用“作物编码 + 目标等级”作为唯一奖励键。配方材料必须包含触发作物，发放时不检查玩家是否拥有其他材料、对应种植权或制作建筑。
- 五十条升级配方及材料以本规格 Further Notes 中的配置基线为准；不能在运行时随机替换。
- 配方需要记录制作入口或前置条件。Demo2.8 只建立配置、资格和缺少条件的可见提示，不实现牛奶、鸡蛋、蛋糕制作或蛋糕架销售。
- “橙果酸奶冻”与其他奶制名称仍使用牛奶材料，不新增酸奶原料。
- 已获得且当前制作入口未开放的配方保持可见；页面展示所缺作物种植权、牛奶、鸡蛋、饮品店品类或蛋糕店能力。
- 已获得配方继续遵循现有顾客订单规则进入有效配方池；订单生成不检查玩家是否拥有完整材料来源。
- 种子商店读取启用的金币商店来源配置，出售永久种植权而非消耗型种子。初始继续提供既有且不与前十级固定赠送冲突的配置商品；具体商品、价格和等级门槛由获得渠道配置决定。
- 同一种作物的等级赠送来源与种子商店来源不得同时启用；服务端拒绝重复购买玩家已永久拥有的作物。
- 白菜、土豆、辣椒、玉米和月光莓不进入前十级固定赠送表。普通作物可通过配置进入种子商店、任务、活动或更高等级；月光莓继续保留为既有限时稀有作物，不在 Demo2.8 改为永久作物。
- 种子商店购买、金币扣除和永久种植权创建位于同一事务；重复或并发购买只能成功一次。
- 四个农田区块均为 4×4：农田 A、B、C、D 分别在小岛一级、三级、五级和八级开放购买资格。
- 四区购买总价分别为 1,300、2,150、4,300、7,500 金币，六十四格总价 15,250 金币；只有农田 A 的首格价格为零并由新玩家初始化获得。
- 购买土地要求目标格与同一区块至少一个已购格上下左右相邻；对角线、跨区块或隔空土地不满足条件。
- 玩家达到区块等级只获得购买资格，不会自动获得整区土地。已购土地永久保留，后续配置调整不回收、不补差价也不退款。
- 土地与区块配置保存稳定编码、局部坐标、地图位置、尺寸、显示顺序、等级门槛、价格、免费初始标记和启用状态；同区局部坐标必须唯一，全局只能有一个免费初始格。
- 种植时把作物等级、成熟秒数、单次产量、收获经验和权限类型保存为本轮快照；浇水后以服务器时间开始成熟倒计时。
- 购买、种植、浇水、收获、作物升级和种子商店购买均以 JWT 对应玩家为唯一身份来源，不能接受请求体中的玩家标识。
- 收获清空土地、增加背包、增加玩家经验和触发小岛升级处于同一事务；重复或并发收获不能重复发放。
- 客户端继续由权威初始化数据读取作物、等级、永久种植权、商店来源和土地，不在页面中复制服务端数值。
- 地图农田位置继续由 FarmConfig 管理；服务端土地局部坐标与客户端区块位置共同决定点击区域。

## Testing Decisions

- 测试只验证公开 JWT HTTP 响应、真实持久化结果和完整页面可见行为，不测试私有方法、内部调用次数或数据库实现细节。
- 主要服务端接缝为认证后的农田与作物 HTTP API：初始化读取、购买土地、种植、浇水、收获、升级作物、读取种子商店和购买永久种植权。
- 数据库测试使用真实测试数据库和约束，覆盖十种作物的一百条等级配置、五十条奖励关系、永久种植权唯一性、土地坐标唯一性以及全局唯一免费初始格。
- 时间只在系统边界可控；测试通过推进服务器时间验证未成熟拒绝、完整成熟时间、快照不受升级或后台改配置影响。
- 事务测试覆盖升级扣金币与配方发放、商店扣金币与种植权发放、土地扣金币与购买状态、收获背包与经验结算。
- 并发测试覆盖同一作物升级、同一商店商品购买、同一土地购买和同一成熟作物收获，验证最多一次成功且资产不重复。
- 配置契约测试验证成长公式的取整、最低 30 秒、产量封顶 8、金币倍率、奖励节点以及每条奖励配方都包含触发作物。
- 客户端接缝为完整小岛页面：打开空土地选择作物、查看与升级作物、查看固定奖励、打开种子商店、购买种植权、购买相邻土地、浇水、倒计时和收获。
- 页面测试验证未拥有、已拥有、等级不足、金币不足、暂不可制作配方和未来入口提示等可见状态。
- 参考现有农田服务测试、作物升级服务测试、JWT 饮品店 HTTP 测试、地图土地交互和页面脚本回归测试。

## Out of Scope

- 不实现牛棚、奶牛、牛奶生产、鸡舍、鸡或鸡蛋生产。
- 不实现蛋糕制作、蛋糕店装修、两个蛋糕架或蛋糕销售。
- 不实现独立运营后台页面、后台写接口、审核发布流程或配置编辑 UI。
- 不引入会在种植时消耗的种子背包、种子数量、仓库容量或作物过期。
- 不改变月光莓既有的限时稀有作物定位，也不设计新的随机奖励池。
- 不实现小岛十一级以后的主线作物奖励，也不为白菜、土豆、辣椒或玉米设计新的十级奖励配方。
- 不修改 Demo2.7 已确定的小岛经验曲线、饮品店装修或每日满意度规则。
- 不实现配方中尚未开放的未来制作入口；仅保存资格并展示条件。
