# 01 — 建立累计小岛等级配置与固定奖励

**What to build:** 建立一级至十级累计玩家经验阈值、小岛等级固定作物种植权与等级赠送配方配置、玩家逐级奖励领取记录，并让 JWT 游戏初始化返回权威成长状态。迁移现有玩家时不得降低等级或遗漏当前等级及以下奖励。

**Blocked by:** None — can start immediately

**Status:** resolved

## Acceptance criteria

- [x] 先通过 JWT 游戏初始化公共接缝写出失败测试，再实现迁移与最小读取行为
- [x] 一级至十级累计经验阈值为 0、100、250、450、700、1000、1400、1900、2500、3200
- [x] 一级至十级固定配置草莓、胡萝卜、橙子、番茄、蓝莓、苹果、西瓜、小麦、柠檬、黄瓜的永久作物种植权
- [x] 一级至十级固定配置草莓汁、胡萝卜汁、橙汁、番茄汁、牛奶冰淇淋、苹果胡萝卜汁、西瓜牛奶冰淇淋、草莓蛋糕、柠檬牛奶冰淇淋、黄瓜苹果汁的等级赠送配方
- [x] 等级赠送配方不随机、不进入其他提前获取渠道，发放时不检查材料或建筑能力
- [x] 新玩家初始化时幂等获得一级作物种植权、草莓汁配方和一级奖励领取记录
- [x] 现有玩家登录时可补齐当前等级及以下缺少的奖励，重复初始化不会重复发放
- [x] 玩家等级奖励记录以玩家和小岛等级唯一约束保证幂等
- [x] 现有玩家迁移后保留当前等级、金币和已有资格，经验转换为累计语义且不会导致降级
- [x] JWT 初始化只返回当前玩家的累计经验、当前等级、下一等级阈值、等级奖励和已领取状态
- [x] 配方暂不可制作时，响应足以表达缺少材料来源或后续店铺能力的引导
- [x] 正式数据库迁移与测试数据库结构保持一致，并兼容已有数据
- [x] 行为测试覆盖新玩家、老玩家补发、重复初始化、多玩家隔离和缺少后续能力的配方资格
