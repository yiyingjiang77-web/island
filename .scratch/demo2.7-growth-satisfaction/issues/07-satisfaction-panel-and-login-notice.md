# 07 — 呈现满意度面板、最近记录与登录礼品通知

**What to build:** 在饮品店提供一个小入口打开满意度面板。面板用紧凑区域显示今日进度，直接展示最近记录，并通过小规则按钮按需展开计算方式和五档礼品；登录自动补发礼品时展示通知。

**Blocked by:** 06 — 呈现小岛成长与饮品店装修交互

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 先通过完整页面脚本行为测试写出失败测试，再实现最小客户端交互
- [ ] 饮品店主界面只显示小型满意度入口，不直接铺开展示全部规则
- [ ] 点击入口打开统一面板，今日进度位于面板内较小区域
- [ ] 今日进度显示交付订单数、拒绝订单数、交付总份数、满意度和预计档位
- [ ] 未达到二十份时显示距离礼品资格还差的份数
- [ ] 达到资格后显示当前档位以及距离下一档的满意度差值
- [ ] 面板直接展示最近一个月有处理订单的日结记录
- [ ] 没有处理订单的日期不生成空白行
- [ ] 最近记录显示日期、交付与拒绝结果、交付总份数、满意度、档位和已发礼品
- [ ] 面板内的小规则按钮按需展开满意度公式、二十份门槛和五档区间
- [ ] 规则按钮再次点击可以收起内容，主面板保持简洁
- [ ] 登录自动补结并发放一日或多日礼品后展示结果通知
- [ ] 礼品通知不提供领取按钮，关闭通知不会影响已经到账的奖励
- [ ] 刷新或再次打开满意度面板不会重复显示为新发放或重复请求发奖
- [ ] 加载、空记录和服务端失败均有明确可见状态
- [ ] 页面不硬编码档位、阈值或礼品内容，全部使用服务端权威响应
- [ ] 客户端 TypeScript、完整页面行为回归、内联脚本语法和真实页面交互验证通过
