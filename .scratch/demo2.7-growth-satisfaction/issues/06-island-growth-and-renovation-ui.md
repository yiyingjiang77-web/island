# 06 — 呈现小岛成长与饮品店装修交互

**What to build:** 在现有页面中展示小岛等级、累计经验进度、逐级升级奖励和饮品店装修入口。玩家可以预览下一级门槛与收益、确认支付金币，并在成功后看到队列和吧台配置刷新。

**Blocked by:** 05 — 结算每日满意度与五档自动礼品

**Status:** resolved

## Acceptance criteria

- [x] 先通过完整页面脚本行为测试写出失败测试，再实现最小客户端交互
- [x] 页面展示当前小岛等级、累计经验、下一级阈值和进度
- [x] 十级时展示已达到当前最高等级，不显示不存在的下一等级进度
- [x] 一次跨多级时按等级顺序展示每一级获得的作物种植权和等级赠送配方
- [x] 暂不可制作的配方仍显示为已拥有，并展示缺少材料来源或店铺能力的引导
- [x] 饮品店装修入口展示当前等级和下一等级预览
- [x] 下一等级预览包含所需小岛等级、装修金币和全部经营数值变化
- [x] 小岛等级不足时按钮不可执行并显示所需等级
- [x] 金币不足时按钮不可执行并显示缺少金币
- [x] 装修需要明确确认，成功后刷新玩家金币、饮品店等级、顾客队列和吧台状态
- [x] 六个室外吧台在所有饮品店等级均保持可点击和可用
- [x] 单吧台上架数量选择器采用服务端返回的当前等级上限
- [x] 装修失败不会在客户端提前扣金币或改变显示等级
- [x] 页面不硬编码等级阈值、金币、队列容量、上架上限或时间间隔
- [x] 客户端 TypeScript、现有页面回归、内联脚本语法和与风险相称的真实页面验证通过
