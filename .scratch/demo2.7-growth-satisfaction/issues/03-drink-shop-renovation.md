# 03 — 建立饮品店一级至十级装修

**What to build:** 建立饮品店等级与装修配置、每位玩家的饮品店等级状态，以及 JWT 权威读取和逐级装修操作。小岛等级只开放资格，玩家必须支付目标等级配置金币。

**Blocked by:** 02 — 结算累计经验并连续发放升级奖励

**Status:** resolved

## Acceptance criteria

- [x] 先通过 JWT 饮品店读取与装修 HTTP 接缝写出失败测试，再实现迁移和事务
- [x] 每位玩家初始化为一级饮品店，六个室外吧台从一级起全部可用
- [x] 目标等级一至十所需小岛等级分别为一至十
- [x] 目标等级一至十装修金币依次为免费、500、1000、2000、3500、5500、8000、11000、15000、20000
- [x] 玩家只能装修到当前饮品店等级的下一级，不能跳级或重复购买
- [x] 小岛等级不足时拒绝装修且不扣金币
- [x] 金币不足时拒绝装修，并返回所需金币、当前金币和缺少数量
- [x] 装修成功在同一事务中锁定玩家、扣除金币并提升一级
- [x] JWT 是唯一玩家身份来源，请求体伪造玩家编号无效
- [x] 重复或并发装修只允许一次成功，不会重复扣金币或跨级
- [x] 读取结果包含当前等级、当前等级完整经营配置、下一等级门槛、金币成本和收益预览
- [x] 五级配置表达冰淇淋制作能力，十级配置表达高级配方能力；本任务不实现牛奶来源
- [x] 配置表支持版本、生效时间、启停和面向玩家的本级提升文案
- [x] 正式数据库迁移与测试数据库结构一致，并兼容现有玩家
