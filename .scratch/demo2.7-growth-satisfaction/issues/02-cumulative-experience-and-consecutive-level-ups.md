# 02 — 结算累计经验并连续发放升级奖励

**What to build:** 将玩家经验改为累计值，并把现有收获、顾客订单和吧台收益接入同一个连续升级事务。一次经验结算跨越多个等级时，按顺序幂等发放每一级固定作物种植权与等级赠送配方。

**Blocked by:** 01 — 建立累计小岛等级配置与固定奖励

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 先通过现有收获、顾客订单和吧台 JWT HTTP 公共接缝写出失败测试，再修改经验结算
- [ ] 玩家经验升级后保持累计值，不再扣除当前等级阈值
- [ ] 当前等级由累计经验阈值决定但只升不降
- [ ] 一次收益跨越多个阈值时连续提升全部可达等级
- [ ] 连续升级按等级升序发放每一级固定作物种植权、等级赠送配方和提示
- [ ] 收获作物按本轮收获经验快照结算一次玩家经验
- [ ] 顾客订单按实际交付份数和单份经验快照结算玩家经验
- [ ] 吧台收取和下架只按实际已售份数与单份经验快照结算玩家经验
- [ ] 单纯制作、上架、暂时没货和退回未售库存不发玩家经验
- [ ] 玩家行锁、经验变更、等级变更和全部逐级奖励在同一事务内完成
- [ ] 重复或并发结算不会丢失经验、重复升级或重复发放资格
- [ ] 返回结果包含结算前后等级、累计经验、下一级阈值和本次逐级奖励
- [ ] 配置阈值提高后，已有玩家等级不会被降低
- [ ] 测试覆盖恰好达到阈值、一次跨多级、十级封顶、零经验、多玩家隔离和并发收益
