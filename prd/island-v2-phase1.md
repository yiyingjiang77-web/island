# 海岛日记 — 第一期 PRD (Phase 1)

## 版本

Phase 1 MVP — 微信小程序  
目标：4-6 周交付一个**可玩的完整游戏**

---

## Problem Statement

现代人需要一个安全的情绪出口和治愈空间。现有日记 App 功能单一，写了就忘，缺乏仪式感和持续动力。用户需要一个能温柔承接情绪、有陪伴感、让人愿意每天回来的数字空间——有社交互动但不制造压力，有种植经营但不变成打卡机器。

---

## Solution

**海岛日记**是一个以"治愈海岛"为场景的情绪日记 + 田园生活 + 社交互动游戏。

核心循环：**写日记选心情 → 种菜种花（心情影响加成）→ 收获卖菜 → 偷菜/除虫/浇水（社交获得友币）→ 捡贝壳开珍珠 → 装扮岛屿**

### 单岛结构（第一期）

整个游戏在一座岛上完成，不做双岛划船（第二期再加）：

- 🏠 **主岛**：玩家的日常生活中心——菜园、花园、日记小屋、树林、沙滩、宠物、种子商店、珍珠商店、友币商店、装扮商店

## 核心系统设计

### 1. 日记系统

每天写日记记录心情是游戏的核心仪式。

**操作流程：**
- 打开日记小屋 → 写文字内容 → 选择心情标签（8基础+4特殊）→ 保存

**心情标签体系：**

**8 个基础心情（日常可选）：**

| 标签 | Emoji | 花色映射 | 种植加成 | 触发场景 |
|------|-------|---------|---------|---------|
| 开心 | 😊 | 金色向日葵 | 生长速度 +10% | 加薪、约会、吃到好吃的 |
| 平静 | 😌 | 白色雏菊 | 无特殊加成，最稳定 | 散步、听雨、什么都不想做 |
| 感动 | 🥰 | 粉色玫瑰 | 收获时额外 1 友币 | 被关心、收到礼物 |
| 思念 | 💭 | 蓝紫色薰衣草 | 树林多刷 1 个蘑菇 | 想一个人、想家乡 |
| 期待 | ✨ | 黄色蒲公英 | 下次收获产量 +5% | 明天有计划、新开始 |

| 焦虑 | 😰 | 靛青铃兰 | 树林寻宝贝壳概率 +15% | 考试、面试、deadline |
| 生气 | 😡 | 红色火棘 | 有概率触发"暴躁南瓜"（卖价翻倍） | 被惹到、不公平 |

|------|-------|---------|---------|---------|
| 治愈 | 🌿 | 绿色四叶草 | 完成「海鸥邮差的烦恼」故事线 | 所有作物收获量 +10% |

### 2. 种植系统

#### 2a. 菜园（经济驱动）

菜的核心循环是 **投入时间 → 收获 → 卖钱 → 买种子**，偏"经营感"。

**种菜步骤：**

```
1. 逛种子商店 → 选种子 → 花星币购买
2. 回菜园 → 选空地 → 种下种子
3. 等待生长 → 每阶段需浇水（水分系统）
4. 除虫（如果长了虫）→ 自己除或求助邻居
5. 成熟 → 收菜 → 可卖/可送/可被偷
6. 卖给收购船 → 获得星币
```

**生长阶段（4 阶段）：**

| 阶段 | 视觉表现 | 时间 | 可操作 |
|------|---------|------|--------|
| 🌱 幼苗 | 一小团绿芽 | 播种后立刻 | 浇水、施肥 |
| 🌿 成长 | 叶片展开 | 总时长的 40% | 浇水、除虫 |
| 🍃 旺盛 | 接近成熟 | 总时长的 70% | 浇水、除虫 |
| 🥕 成熟 | 完整形态，高亮标记 | 100% | 收菜！ |

**水分系统：**
- 每块地有水分值（初始 100，每 4 小时自然 -10）
- 水分降到 0 → 作物**暂停生长**（不死）
- 主人浇水 → 水分恢复到 100
- 连续 2 天没浇水 → 作物长虫

**菜园作物表（第一期 Lv1~15）：**

| 作物 | 种子价格 | 生长时间 | 保底产量 | 可偷溢出 | 卖价(每个) | 解锁等级 |
|------|---------|---------|---------|---------|----------|---------|
| 小白菜 | 5 星币 | 30min | 2个 | 1~3个 | 3 星币 | Lv1 |
| 胡萝卜 | 10 星币 | 1h | 2个 | 0~2个 | 8 星币 | Lv1 |
| 畫茄 | 15 星币 | 2h | 3个 | 0~3个 | 6 星币 | Lv3 |
| 土豆 | 20 星币 | 3h | 4个 | 0~4个 | 5 星币 | Lv5 |
| 辣椒 | 30 星币 | 4h | 2个 | 0~1个 | 20 星币 | Lv7 |
| 玉米 | 50 星币 | 5h | 1个 | 0~1个 | 40 星币 | Lv10 |
| 🎃 暴躁南瓜 | 40 星币 | 6h | 1个 | 0个 | 80 星币 | 😡时触发,Lv5 |

**保底随等级增加：**

| 等级段 | 保底加成 | 示例（小白菜） |
|--------|---------|--------------|
| Lv1~3 | 基础保底 | 保底 2个 |
| Lv4~6 | 保底 +1 | 保底 3个 |
| Lv7~9 | 保底 +2 | 保底 4个 |
| Lv10~15 | 保底 +3 | 保底 5个 |

**种菜操作：**

| 操作 | 说明 | 消耗 |
|------|------|------|
| 浇水 | 水分恢复100 | 免费 |
| 施肥 | 生长速度+30%（仅当前阶段） | 10星币 |
| 除虫 | 清除害虫 | 自己除免费 |
| 收菜 | 收获成熟作物（保底+剩余溢出） | 点击即收 |
| 翻地 | 收完后翻地才能种新的 | 1次点击 |

#### 2b. 花园（情绪驱动）

花的核心循环是 **写日记 → 花自动生长 → 花留在花园 → 形成情绪地图**，偏"收藏感"。

**种花步骤：**

```
1. 写日记 → 选择心情标签
2. 系统根据心情 → 自动在花园生成一朵花苗
3. 花苗自然生长 → 不需要浇水施肥
4. 24小时后 → 花完全绽放，永久留在花园
5. 花不可卖、不可偷 → 只能观赏和回顾
6. 花园里点击任意花 → 看到当天的那篇日记
```

**花为什么不需要照料？**
- 花是日记的情感结晶，不是劳作产物
- 如果花也要浇水施肥，写日记变成了"又多了一件事"，破坏治愈感

**花的生长阶段（3 阶段）：**

| 阶段 | 视觉表现 | 时间 |
|------|---------|------|
| 🌱 花苗 | 小绿芽，颜色隐隐可见 | 写完日记立刻 |
| 🌷 半开 | 花苞，颜色明确 | 6小时后 |
| 🌻 绽放 | 完整花朵，永久盛开 | 24小时后 |

**心情→花对照表：**

| 心情 | 花名 | 花色 | 花形态特征 |
|------|------|------|----------|
| 😊 开心 | 向日葵 | 金色 | 大朵、圆盘、向上 |
| 😌 平静 | 雏菊 | 白色 | 小朵、简约、安静 |
| 🥰 感动 | 玫瑰 | 粉色 | 圆润、花瓣层叠 |
| 💭 思念 | 薰衣草 | 蓝紫 | 成串、穗状 |
| ✨ 期待 | 蒲公英 | 黄色 | 轻盈、球形 |
| 😢 难过 | 勿忘我 | 蓝色 | 小簇、倔强 |
| 😰 焦虑 | 铃兰 | 靛青 | 垂坠、钟形 |
| 😡 生气 | 火棘 | 红色 | 带刺、尖锐 |
| 🌿 治愈 | 四叶草 | 绿色 | 稀有、小巧 |
| 🌙 浪漫 | 月见草 | 夜光粉 | 夜间发光 |
| 🔥 勇气 | 帝王花 | 红橙 | 巨大、霸气 |
| 💐 珍惜 | 绣球花 | 七彩渐变 | 球形、变色 |

**难过时种菜的交叉联动：**
- 😢 难过时种菜 → 收获时额外掉一朵"心情花"（蓝白色小野花，自动种到花园）
- 这是唯一从菜园流入花园的花——即使没写日记，难过的心情也会被花园记录

### 3. 社交互动系统

#### 3a. 偷菜（鼓励社交）

**设计原则：偷菜不是偷窃，是社交活动。偷菜获得友币，被偷说明你的菜园受欢迎。**

**偷菜规则：**

| 规则 | 说明 |
|------|------|
| 每日偷菜上限 | **10 次** |
| 同一邻居每天 | 只偷 **1 次**（10次分散到10个邻居） |
| Lv1~3 新手 | 菜园不可被偷（保护期） |
| 偷取范围 | 只能偷**溢出部分**，保底不可偷 |
| 每次偷取量 | 1~3 个（随机），不超过溢出总量 |

**偷菜收益：**

| 偷菜结果 | 获得奖励 |
|---------|---------|
| 偷到作物 | 1~3个作物 + **2 友币** |
| 没偷到（溢出已收完） | **1 友币**（安慰奖，白跑一趟也有收获） |

**友币递减机制（防刷但归零）：**

| 次数 | 友币收益 |
|------|---------|
| 1~5次 | 每次 2 友币 |
| 6~8次 | 每次 1.5 友币 |
| 9~10次 | 每次 1 友币 |

**偷菜成功文案（社交感，非惩罚感）：**

| 场景 | 文案 |
|------|------|
| 偷到 | "从XX的菜园摘了2个胡萝卜，味道不错！+2友币" |
| 没偷到 | "XX今天已经收菜了，下次早点来~ 还是+1友币" |
| 被偷通知 | "XX来你的菜园串门了，顺手摘了2个番茄" |
| 被偷汇总 | "你的菜园很受欢迎！今天有3个朋友来摘菜" |

**偷菜排行榜：**

| 排行榜 | 意义 |
|--------|------|
| 本周偷菜达人 | 最活跃社交玩家 |
| 最受欢迎菜园 | 被偷最多 = 菜种得好、人气高 |
| 最佳邻居 | 偷菜+除虫+浇水+送菜 总互动次数 |

#### 3b. 除虫（正向互助）

**虫子来源：**
- 种植时随机 5% 概率长虫
- 偷菜失败 20% 概率给自己长虫
- 3天没浇水 → 必定长虫

**除虫互助：**

| 规则 | 说明 |
|------|------|
| 每天帮邻居除虫上限 | **3 次** |
| 除虫奖励 | **5 星币 + 2 友币** |
| 主人收到通知 | "XX帮你除掉了害虫！" |

**心情联动：**
- 😊 开心时帮除虫 → 额外 **1 友币**
- 😢 难过时帮除虫 → 额外 **1 珍珠碎片**（10碎片=1珍珠）

#### 3c. 助力浇水（解决缺水）

**缺水来源：**
- 每块地水分值自然下降（每4小时-10）
- 水分0 → 作物暂停生长
- 连续2天不浇水 → 长虫

**助力浇水：**

| 规则 | 说明 |
|------|------|
| 每天帮邻居浇水上限 | **5 次** |
| 浇水恢复量 | **30 水分**（主人自己浇恢复100） |
| 浇水奖励 | **3 星币 + 1 友币** |
| 主人收到通知 | "XX帮你浇了水，作物恢复生长啦！" |

**求水广播：**
- 主人可发求水广播："我的番茄快干死了，求助力！"
- 好友列表看到求水标记 → 优先去浇水
- 被助力浇水 ≥3 次 → 收获时额外产出 1 个

#### 3d. 送菜（深度社交）

| 规则 | 说明 |
|------|------|
| 每天送菜上限 | **2 次** |
| 送菜奖励 | **3 友币**（单次最高） |
| 对方收到通知 | "XX送了你一棵小白菜！" |

## 每日完整循环

```
早上：写日记选心情 → 花园自动长花苗 → 菜园获得心情加成
      → 收成熟作物 → 发现有几块地缺水/长虫 → 发求水广播

      → 偷菜（赚友币，最多10次）

      → 沙滩捡贝壳 → 开珍珠

晚上：喂宠物 → 看花园里的心情花 → 回顾日记
      → 明天要收菜，不然溢出部分会被摘走
```

### 保底机制专项测试

- 作物保底产量 = guaranteed_base + level_bonus
- 溢出部分 = total - guaranteed - 已被偷总量 ≥ 0 才可偷
- 被偷总量 ≤ 溢出总量（并发偷取加锁）
- 主人收获 = guaranteed_base + level_bonus + 剩余溢出
