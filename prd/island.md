# 海岛日记 — 产品规格书 (PRD)

## 版本

MVP v1.0 — 微信小程序

---

## Problem Statement

现代人需要一个安全的情绪出口和治愈空间。现有日记 App 功能单一，写了就忘，缺乏仪式感和持续动力。用户需要一个能温柔承接情绪、有陪伴感、让人愿意每天回来的数字空间——不需要社交压力，只需要被理解和陪伴。

---

## Solution

**海岛日记**是一个以"治愈海岛"为场景的情绪日记 + 田园生活游戏。

核心循环：**写日记记录心情 → 种菜/种花/种树 → 收获售卖 → 装扮岛屿与人偶 → 探索岛与 NPC 互动治愈内心**。

### 双岛结构

整个海岛由两座岛屿组成，人偶可以划小船往返：

- 🏠 **主岛（家岛）**：玩家的日常生活中心——菜园/花园/果园、树林、沙滩、宠物、小窝、服装商店、珍珠兑换商店。这是你"住"的地方，有日常任务和经济循环。
- 🧭 **探索岛**：与 NPC 互动的专属场所，**没有日常任务压力**。岛上有各种角色——动物 NPC（如老海龟、海鸥邮差、灯塔守护者）和 NPC 岛民（有固定人设的虚拟角色）。每个 NPC 有独立的性格和对话库，由**管理后台**配置。NPC 根据玩家**当日心情标签**匹配对应的对话内容——😊开心时活泼热情；😢难过时温柔安慰；😡生气时陪你吐槽；😰焦虑时引导放松。探索岛是你与岛上居民建立羁绊的地方。

### 划船

人偶从主岛沙滩码头划小船前往探索岛（或返回）。航行是纯视觉过渡动画，伴随海浪声，时长约 8-12 秒（可跳过）。每日往返不限次数。

### 日记系统

每天写日记记录心情是游戏的核心仪式。玩家选择当日心情标签（😊😢😡😰🥰 等）和话题标签（#工作 #感情 #家庭 #成长 #随便聊聊 等），写下文字内容。日记仅自己可见，可在日记本中按日期或心情回顾历史记录。

> **设计说明**：MVP 阶段日记为纯私人记录，不做公开分享。分享/社交功能在后续版本酌情开放。

支撑系统：主岛上有菜园（Lv1 解锁）/花园（Lv8 解锁）/果园（Lv18 解锁）（种植收获售卖，未解锁土地加锁显示）、树林（探索与动物互动）、沙滩（捡贝壳开珍珠）、宠物（陪伴）、服装商店（装扮人偶）、珍珠兑换商店。探索岛上有多个 NPC 角色可互动、心情轨迹展览。所有活动通过情绪标签串联——你今天的心情像"岛上的天气"一样影响各处体验。

## User Stories
### 用户与身份

1. As a 新玩家, I want 创建一个正常人偶形象并起一个岛名, so that 我在岛上有一个代表自己的身份
2. As a 玩家, I want 在服装商店里用星币或元宝购买好看的服装/发型/配饰来装扮人偶, so that 我在岛上和邻居面前有自己的风格
3. As a 玩家, I want 在猫/狗/兔子中三选一作为宠物伙伴（选定不可更换）, so that 岛上有一个陪伴我的小生命
### 日记与心情
4. As a 玩家, I want 每天写日记，记录文字内容并选择一个心情标签（😊😢😡😰🥰 等）, so that 我的情绪有处可放
5. As a 玩家, I want 写日记时可选话题标签（#工作 #感情 #家庭 #成长 #随便聊聊 等）, so that 我的日记可以被更好地理解和匹配
6. As a 玩家, I want 回顾自己过去的日记和对应的心情, so that 看到自己的情绪轨迹

### 沙滩

7. As a 玩家, I want 在沙滩捡到不同品级的贝壳（小白贝/粉色扇贝/金色扇贝/紫色海螺）, so that 有收集和期待感
8. As a 玩家, I want 打开贝壳获得珍珠（品级越高珍珠越多，珍珠为稀缺资源）, so that 捡到稀有贝壳是真正的惊喜

### 珍珠兑换商店

9. As a 玩家, I want 在珍珠兑换商店里使用珍珠兑换各种物品, so that 珍珠有多种消费出口
10. As a 玩家, I want 在兑换商店中珍珠→星币按 1:10 固定汇率兑换, so that 我有选择如何花珍珠的自由
11. As a 玩家, I want 兑换商店货架包含：加速肥料 / 稀有种子盲盒 / 珍珠限定装扮 / 珍珠→星币兑换, so that 商店内容丰富

### 菜园/花园/果园

12. As a 玩家, I want Lv1 时菜园解锁拥有 2 块菜地，花园和果园土地上显示加锁状态, so that 随着等级提升逐步解锁更多种植空间
13. As a 玩家, I want Lv8 时花园解锁获得 1 个花圃, so that 可以开始种花
14. As a 玩家, I want Lv18 时果园解锁获得 1 个果树坑, so that 可以开始种果树
15. As a 玩家, I want 随着等级提升免费解锁更多地块, so that 成长带来更多种植空间
16. As a 玩家, I want 种植蔬菜（短周期，小时级）、花卉（中周期，天级）、果树（长周期，种下后每日结果）, so that 有不同的种植策略
17. As a 玩家, I want 收菜时偶尔触发"稀有品种"弹窗，花费 50 友币可收获稀有品种, so that 社交货币有明确的消费出口
18. As a 玩家, I want 蔬菜被好友"摘取"时我不损失作物且获得友币, so that 被摘菜是开心的社交体验而非损失
19. As a 玩家, I want 随着作物升级被更多好友摘取（Lv1:1个、Lv3:2个、Lv5:3个）, so that 升级有社交回报
20. As a 玩家, I want 每日早上 7 点有一艘船来收购蔬菜/水果/鲜花/稀有品种（各有定价）支付星币, so that 种植有稳定的经济回报
21. As a 玩家, I want 新玩家获得 2000 星币和一些初始种子, so that 可以立刻开始种植和售卖

### 树林

22. As a 玩家, I want 主动找小野猪对话，它根据我当日心情先讲冷笑话安慰、再给出可验证的指引（"东边有蘑菇"→真的刷出蘑菇）, so that 对话有信任感和功能性
23. As a 玩家, I want 骑上小野猪在岛上兜风（MVP 纯视觉体验）, so that 有治愈的视觉体验
24. As a 玩家, I want 找小松鼠对话得知哪棵树上有松子→走过去摇树→松子掉落→收集卖珍珠, so that 树林探索有收获
25. As a 玩家, I want 每天在树林里有一次寻宝机会获得随机物品, so that 有每日期待

### 宠物

26. As a 玩家, I want 宠物（猫/狗/兔）纯陪伴——在家和花园里自由走动、可以抚摸和喂食, so that 岛上有生命陪伴感
27. As a 玩家, I want 宠物偶尔出走一段时间→回来后带回小礼物或好友种的菜, so that 宠物是社交破冰器
28. As a 玩家, I want 用星币装饰宠物的小窝, so that 我的宠物有独特的家

### 经济系统

29. As a 玩家, I want 星币（一般等价物）购买基础款服装/装饰/宠物窝, so that 免费玩家有完整的装扮体验
30. As a 玩家, I want 元宝（付费货币，3元=30元宝）购买稀有/限定装饰和皮肤, so that 付费玩家有独特的视觉差异化
31. As a 玩家, I want 珍珠（稀缺资源，1珍珠=10星币）在兑换商店消费, so that 珍珠有多种策略性用途
32. As a 玩家, I want 星币不可换元宝、元宝不可换星币, so that 稀有物品保持稀缺性

### 岛屿与社交空间

33. As a 玩家, I want 我的海岛是一幅精美插画（旅行青蛙风格），有沙滩/树林/小窝/菜园等热点可点击进入, so that 岛屿有沉浸感和治愈感
34. As a 玩家, I want 去邻居的岛串门——看到对方的小窝装饰、花园、宠物窝、人偶装扮, so that 社交有空间载体
35. As a 玩家, I want 给邻居的菜地浇水/帮忙获得友币, so that 串门是互助而非竞争

### 双岛与航行

36. As a 玩家, I want 海岛由主岛和探索岛两座岛组成，人偶可以划小船在两个岛之间往返, so that 日常生活和情绪探索有空间上的分离
37. As a 玩家, I want 探索岛在玩家达到 Lv5 时解锁, so that 新玩家先熟悉主岛的日常生活，再逐步开启探索治愈空间
38. As a 玩家, I want 主岛承载全部日常生活功能（家/菜园/树林/沙滩/商店），探索岛是纯粹的 NPC 互动空间没有日常任务, so that 去探索岛就是"找岛上的朋友们聊聊天"
39. As a 玩家, I want 探索岛上有多个 NPC 角色，他们根据我当日心情标签做出不同反应和对话, so that 每次去都有新鲜的互动体验
40. As a 玩家, I want 航行约 8-12 秒可跳过, so that 不赶时间的玩家享受过程、赶时间的玩家快速到达
41. As a 玩家, I want 探索岛上有心情轨迹展览（回顾历史心情的视觉化呈现），NPC 也会提及我过去的心情记录, so that 感受到被了解和陪伴

## Implementation Decisions
### 平台架构
- 微信小程序（前端） + 云开发或独立后端（Node.js/Go）
- MVP 阶段先做单服务器架构，后续根据 DAU 拆分微服务
- 图片/静态资源走 CDN，日记内容走数据库
- **实现顺序**：先做主岛的完整功能，探索岛作为 Lv5 解锁的后续阶段开发。MVP 阶段主岛是最高优先级，探索岛可在主岛功能稳定后再启动
### 模块划分
| 模块 | 职责 | MVP 阶段 |
|---|---|---|
| `user` | 账号（微信登录）、身份、邻居关系 | 完整 |
| `diary` | 日记 CRUD、心情标签、话题标签（纯私人记录） | 完整 |
| `shore` | 沙滩贝壳刷新与捡拾 | 完整 |
| `forest` | 寻宝、动物互动（猪/松鼠）、蘑菇/松子采集 | 完整 |
| `garden` | 种植（菜/花/树）、收获、稀有触发、友币系统 | 完整 |
| `pet` | 宠物选择、陪伴状态、出走/回归逻辑、送礼 | 完整 |
| `island` | 主岛插画场景、热点导航（纯前端组件）+ 探索岛场景渲染、心情驱动动态变化 | 完整 |
| `boat` | 划船航行、往返主岛↔探索岛、Lv5 解锁门控 | 完整 |
| `explore-island` | 探索岛 NPC 交互（心情驱动对话/行为）、心情轨迹展览、心情→视觉映射 | 完整 |
| `economy` | 星币/元宝/珍珠/友币账户、交易流水、船收菜定时任务 | 完整 |

| `avatar` | 人偶换装系统（服装/发型/配饰） | 完整 |
| `shop` | 服装商店（星币区 + 元宝区）+ 珍珠兑换商店 + 友币商城 | 完整 |
### API 契约（核心端点）
所有接口通过 `/api/*` 网关层暴露给小程序前端。核心契约：
```
用户：
  POST   /api/user/auth             微信登录授权
  GET    /api/user/profile          获取个人信息
  PUT    /api/user/avatar           更新人偶装扮

日记：
  POST   /api/diary                 创建日记
  GET    /api/diary/:id             获取日记详情
  PUT    /api/diary/:id             编辑日记
  DELETE /api/diary/:id             删除日记
  GET    /api/diary/list            日记列表（按日期/心情筛选）


沙滩：
  GET    /api/shore/state           沙滩当前状态（贝壳刷新）
  POST   /api/shore/collect-shell   捡贝壳/开珍珠

珍珠兑换商店：
  GET    /api/shop/pearl/items      兑换商店货架
  POST   /api/shop/pearl/buy        珍珠兑换商品
  POST   /api/shop/pearl/exchange   珍珠→星币兑换

树林：
  POST   /api/forest/treasure       每日寻宝
  POST   /api/forest/mushroom       小野猪指引后采集蘑菇
  POST   /api/forest/pinecone       摇树捡松子

花园：
  GET    /api/garden/state          花园当前状态
  POST   /api/garden/plant          种植
  POST   /api/garden/harvest        收获（含稀有触发判定）
  POST   /api/garden/pick           好友摘取（无损+友币）
  POST   /api/garden/boat-sell      船收菜出售

宠物：
  GET    /api/pet/state             宠物当前状态
  POST   /api/pet/choose            选择宠物（一次性）
  POST   /api/pet/feed              喂食
  GET    /api/pet/adventure         出走归来结果

好友：
  GET    /api/friend/list           好友列表
  POST   /api/friend/random         随机推荐 20 人
  POST   /api/friend/request        发送好友申请
  POST   /api/friend/accept         同意申请

经济：
  GET    /api/wallet                账户余额（星币/元宝/珍珠/友币）

服装商店：
  GET    /api/shop/clothing/items   服装商品列表（星币区+元宝区）
  POST   /api/shop/clothing/buy     购买服装

双岛航行：
  POST   /api/boat/travel           发起航行（主岛→探索岛 或 探索岛→主岛）
  GET    /api/boat/daily-status     当日航行次数

探索岛：
  GET    /api/explore-island/state  获取探索岛当前状态（视觉主题/NPC 列表/心情驱动对话，由当日心情标签驱动）
  GET    /api/explore-island/mood-trail  心情轨迹展览数据（历史心情可视化）
  POST   /api/explore-island/talk        与指定 NPC 对话（NPC 根据心情标签生成回应）
```

## Testing Decisions

### 测试接缝

最高测试接缝是 **API 网关层**（`/api/*`），所有测试从 API 契约层面切入，不依赖 UI。

### 每个模块的测试策略

| 模块 | 测试重点 |
|---|---|
| `diary` | 日记 CRUD、心情标签、话题标签（纯私人记录） | 完整 |
| `shore` | 沙滩贝壳刷新与捡拾 | 完整 |
| `forest` | 寻宝每日限制、小野猪指引→资源实际刷新验证、松子掉落 |
| `garden` | 种植→生长→收获完整生命周期、稀有触发概率、友币记录、船收菜定时任务 |
| `pet` | 三选一不可更改、出走/回归状态机、礼物生成 |
| `economy` | 四币种账户隔离、交易流水完整性、珍珠兑换汇率 1:10 正确性、船收菜批量结算 |
| `shop` | 服装商店购买、珍珠兑换商店货架/兑换 |
| `friend` | 邻居关系申请/同意流转 |
| `boat` | 航行方向校验、Lv5 解锁门控 |
| `explore-island` | 心情标签→NPC 对话/行为映射正确性、心情轨迹展览数据完整性、NPC 互动频率 |

### 好的测试标准

- 测试外部行为（API 输入→输出），不测试内部实现
- 每个 API 端点至少覆盖：正常流程 + 边界条件 + 错误状态
- 定时任务（船收菜、心情过期、每日刷新）用可控时钟 mock
- 概率型逻辑（贝壳品级、稀有触发）用固定种子验证分布落在预期范围内

## Further Notes

### 视觉风格参考

- 主场景：旅行青蛙式的精美插画海岛
- 配色：暖沙色 + 海蓝 + 森林绿 + 奶油白
- 动效：海浪轻拍、树叶摇动、宠物闲逛（轻微 GIF/帧动画）
- 字体：圆体/手写体，强化治愈感

### 情绪设计原则

整座岛围绕"你今天的心情"运转。所有子系统的文案和视觉反馈应根据用户当日心情做微调，**探索岛是情绪设计的最集中体现**：

- 😊 开心 → 主岛阳光明媚、动物对话活泼；探索岛 NPC 热情互动、赠送小礼物
- 😢 难过 → 主岛下起小雨（仅视觉层）、小野猪先讲笑话再给指引、宠物靠近频率增加；探索岛 NPC 主动靠近安慰、讲温暖的故事
- 😡 生气 → 主岛树林多刷一个蘑菇供"发泄散步"；探索岛 NPC 陪你一起吐槽、提供"对着大海喊出来"互动
- 😰 焦虑 → 主岛树林多刷一个探索点；探索岛 NPC 话语舒缓、引导冥想、提醒"你被很多人爱着"

（MVP 阶段仅做文案差异化，不做概率倾斜）

### 日常节拍设计

```
07:00  船来收菜（每日经济结算）+ 贝壳刷新
全天   种植/收获/寻宝/森林动物互动（自由活动）
全天   写日记记录心情（核心仪式）
全天   沙滩捡贝壳开珍珠
全天   🚣 划船往返主岛↔探索岛（Lv5 解锁）→ 与 NPC 互动
次日   贝壳刷新 + 寻宝次数重置
```
