# Demo3.0 无限等级体系与经济重平衡设计

> 创建日期：2026-08-01
> 状态：设计阶段

## 1. 设计目标

- **永远不满级**：等级无上限，玩家始终有成长追求
- **三阶段体验**：内容解锁 → 精通成长 → 无限追求
- **经济平衡**：经营比种地更赚钱，金币有足够消耗口
- **数值可控**：精通加成有上限，防止后期数值爆炸

## 2. 无限等级体系

### 2.1 经验公式

```
exp_to_next(level) = 100 × level^1.3
```

Lv1-20 通过 `island_level_config` 表配置解锁内容；Lv21+ 使用公式运行时计算，不存表。

| 等级 | 单级经验 | 累积经验 | 预估耗时* |
|------|---------|---------|----------|
| 2 | 100 | 100 | ~5 分钟 |
| 5 | 810 | 1,353 | ~40 分钟 |
| 10 | 1,995 | 7,743 | ~4 小时 |
| 20 | 4,912 | 31,548 | ~16 小时 |
| 50 | 11,180 | 168,723 | ~4 天 |
| 100 | 19,953 | 655,961 | ~2 周 |
| 200 | 49,124 | 4,068,037 | ~2 个月 |

\*预估基于每小时 ~2000 经验（订单交付 + 收获 + 吧台）

### 2.2 三阶段设计

**阶段一（Lv 1-20）内容解锁期**

每级通过 `island_level_config` 表配置解锁：
- 作物种植权（草莓/小麦/苹果/玉米/白菜/菠萝等）
- 配方（饮品/蛋糕）
- 建筑（蛋糕店/交易所/温室）
- 人物 NPC（阿海/小铃/花姨/糖糖/小灰）
- 小动物（松鼠/刺猬/知更鸟/小狐狸）
- 隐藏区域（温泉/秘密钓点/秘密花园/精灵树）

新手第一周可体验大部分内容。Lv20 所有核心内容解锁完毕。

**阶段二（Lv 21-100）精通成长期**

无新内容解锁，但每级提供数值提升：
- 每 5 级：作物产量 +5%（上限 +100%）
- 每 10 级：成品售价 +10%（上限 +50%）
- 每级：作物生长时间 -0.5%（上限 -40%）
- 每 25 级：解锁季节限定配方（Lv25/50/75/100）

玩家追求效率优化——同样配方高等级产出更多、卖得更贵。约 3-6 个月。

**阶段三（Lv 100+）无限追求期**

精通加成已全部封顶，纯粹数值积累：
- Lv 200：称号"山谷大师" + 专属装饰
- Lv 500：称号"果香传奇" + 专属装饰
- Lv 1000：称号"不朽之灵" + 专属装饰

### 2.3 精通加成（有上限）

| 加成 | 公式 | 上限 | 封顶等级 |
|------|------|------|---------|
| 产量 | `+floor(Lv/5) × 5%` | +100% | Lv100 |
| 售价 | `+floor(Lv/10) × 10%` | +50% | Lv50 |
| 生长 | `-Lv × 0.5%` | -40% | Lv80 |

Java 实现：

```java
public static double yieldMultiplier(int level) {
    return 1.0 + Math.min(1.0, Math.floor(level / 5.0) * 0.05);
}

public static double priceMultiplier(int level) {
    return 1.0 + Math.min(0.5, Math.floor(level / 10.0) * 0.1);
}

public static double growthMultiplier(int level) {
    return Math.max(0.6, 1.0 - level * 0.005);
}
```

**上限设计理由**：
- 产量上限 +100%（翻倍）：Lv100 时产出翻倍，足够有成就感但不会让后期配方材料溢出
- 售价上限 +50%：避免高等级玩家售价翻倍导致金币通胀，售价增长比产量慢
- 生长上限 -40%：最快生长时间为原来的 60%，保证作物仍有等待感

### 2.4 等级计算

```java
public static long expToNext(int level) {
    return (long) (100 * Math.pow(level, 1.3));
}

public static int calculateLevel(long cumulativeExp) {
    int level = 1;
    long needed = 0;
    while (needed + expToNext(level) <= cumulativeExp) {
        needed += expToNext(level);
        level++;
    }
    return level;
}
```

### 2.5 两套等级合并

当前并行系统：
- `player_level_config`（20 级，旧系统，`game_player.exp` 字段）
- `island_level_config`（10 级，Demo2.7 新增累计经验模式，`game_player.cumulative_exp` 字段）

**合并方案**：统一使用 island_level 累计经验模式
1. `island_level_config` 扩展至 Lv1-20（配置内容解锁奖励）
2. Lv21+ 使用公式计算，不存表
3. 废弃 `player_level_config`
4. `game_player.exp` 字段标记废弃，最终删除

## 3. 经济重平衡

### 3.1 问题诊断

| 问题 | 现状 | 影响 |
|------|------|------|
| 原料售价过高 | 月光莓 120 金/个 | 种地比开店赚钱 |
| 收获经验过高 | 5-40 经验/次 | 5 分钟升一级 |
| 金币消耗不足 | 仅土地+作物升级 | 后期金币堆积 |
| 配方定价扁平 | 30-80 金 | 无高低端差距 |

### 3.2 原料售价调整

原则：原料直接出售几乎不赚钱，引导加工

| 品类 | 现在售价 | 调整后 |
|------|---------|--------|
| 草莓/白菜/苹果 | 5-8 | 2-4 |
| 玉米/菠萝 | 20-40 | 5-10 |
| 月光莓 | 120 | 15-25 |
| 鸡蛋/牛奶 | 5 | 3 |
| 坚果（榛果/松子/栗子） | - | 5-10 |
| 菌菇（口蘑/香菇/鸡油菌） | - | 5-15 |
| 松露 | - | 30-50 |

### 3.3 配方定价调整

原则：加工越多越赚钱，高级配方显著贵于低级

| 配方 | 现售价 | 调整后 | 现经验 | 调整后 |
|------|-------|--------|-------|--------|
| 草莓汁 | 30 | 50 | 5 | 15 |
| 苹果汁 | 25 | 45 | 5 | 12 |
| 玉米汁 | 35 | 65 | 8 | 18 |
| 菠萝汁 | 45 | 90 | 10 | 25 |
| 白菜汁 | 20 | 40 | 5 | 10 |
| 草莓蛋糕 | 80 | 150 | 12 | 35 |
| 玉米蛋糕 | 60 | 130 | 10 | 30 |
| 菠萝蛋糕 | 70 | 140 | 10 | 30 |
| 白菜蛋糕 | 50 | 100 | 8 | 25 |
| 苹果蛋糕 | 50 | 100 | 8 | 25 |
| 菌菇饮品系列 | - | 80-180 | - | 20-40 |
| 菌菇甜品系列 | - | 120-280 | - | 25-60 |
| 联动配方 | - | 160-320 | - | 35-70 |

### 3.4 经验来源调整

| 来源 | 现经验 | 调整后 | 说明 |
|------|-------|--------|------|
| 收获作物 | 5-40 | 1-8 | 种地是手段不是目的 |
| 顾客订单 | 5-12×数量 | 15-80 | 经营是核心经验来源 |
| 吧台收取 | 同订单 | 订单×1.2 | 鼓励提前备货 |
| NPC 任务 | - | 10-50 | NPC 系统产出 |

### 3.5 金币消耗口

| 消耗口 | 金额 | 频率 | 说明 |
|--------|------|------|------|
| 配方商店 | 500-5000/个 | 一次性 | 菌菇配方用金币购买 |
| 种子费用 | 5-50/株 | 每次种植 | 不再免费送 |
| 土地维护费 | 10-100/块/天 | 每日 | 持续消耗 |
| NPC 礼物 | 10-500 | 自愿 | 好感度系统需要 |
| 装饰物 | 100-2000 | 自愿 | 装饰区 |
| 隐藏区域 | 1000-10000 | 一次性 | NPC 好感 + 金币 |

### 3.6 经济循环模型

**金币流向**：

```
产出：订单交付（主要）→ 原料出售（次要，低收益）
          ↓
消耗：种子 → 配方商店 → 土地维护 → NPC 礼物 → 装饰 → 隐藏区域
```

**经验流向**：

```
产出：订单交付（主要）→ 吧台收取（×1.2）→ NPC 任务 → 收获（次要）
          ↓
消耗：升级 → 解锁内容（Lv1-20）→ 精通加成（Lv21-100）→ 称号（Lv100+）
```

## 7. 风险与注意事项

1. **公式性能**：`calculateLevel()` 在高等级时需要循环计算，可加缓存（玩家等级变化频率低）
2. **数值回归测试**：经济调整后需要完整的回归测试，确保没有数值溢出或负数
3. **迁移不可逆**：废弃 `player_level_config` 和 `exp` 字段前，确保所有入口已切换到 `cumulative_exp`
4. **季节限定配方**：Lv25/50/75/100 的季节配方需要额外设计，暂不在本文档定义
