# 海岛日记 — 美食店 & 汐灵系统设计
---
## 系统定位
**美食店**是岛上第一个"经营"玩法——不再只是种菜卖菜，而是把蔬菜加工成美食，卖给岛上的居民和游客。
**汐灵**是岛灵，是美食店的灵魂。它有两个状态值：**饱腹度**和**心情**，都是0~100。喂它蔬菜维持饱腹，它帮你干活；饱腹低于40干活会闯祸——碗碎了、菜里有沙子，顾客打折甚至免单，越饿概率越高（10%→80%）。不干活时饿了还会跑去菜园吃菜踩坏蔬菜（减产2个/块地，但吃完饱腹恢复至80）。喂稀有蔬菜，它触发特殊能力。不饿的时候出去玩，偶尔捡回宝贝。饱腹度决定心情上限（吃饱了心情最多80），抚摸或夸赞可以把心情推到100——心情越高，玩耍发现越好、烹饪加成越高。

核心循环（双版本并存，玩家自由选择）：

```
原版：种菜 → 收菜 → 卖给收购船 → 赚星币+种菜经验 → 升级 → 买种子
新版：种菜 → 收菜 → 美食店加工 → 卖美食 → 赚星币(更高利润)+烹饪经验 → 升级
      → 喂汐灵蔬菜 → 汐灵帮你干活 → 饱腹<40干活会闯祸(10%~80%概率，7折/免单)
      → 不干活+饿着 → 汐灵饿到去菜园吃菜(减产2个/块地,吃完饱腹恢复80)
      → 不干活+不饿 → 汐灵玩耍探索 → 捡宝贝+带回珍贵食材回来
      → 喂稀有蔬菜 → 汐灵特殊能力
      → 抚摸/夸赞 → 心情到100 → 玩耍运气最好+烹饪卖价+10%
      → 看广告 → 双倍金币经验3h / 免费补饭机3h
```

> **设计说明**：收获的菜既能直接卖给收购船（快钱+种菜经验），又能送进美食店加工（高利润+烹饪经验）。收购船每天早上首次登陆时生成，随机选3种蔬菜作为今日高价收购任务。收菜和卖菜都会获得经验，经验用于玩家等级升级，升级后解锁更多菜谱和功能。

## 1. 美食店系统

### 1a. 开店条件

| 条件 | 说明 |
|------|------|
| 等级 | Lv6 开放美食店 |
| 好友数 | **≥ 10 个好友**（经营美食店需要社交基础） |
| 开店费 | 100 星币 + 20 友币 |
| 初始状态 | 6 张餐桌 + 1 个灶台 + 汐灵自动出现 |

### 1b. 美食出餐流程

美食店是**手动经营**——顾客自动来、自动点菜（后端随机生成），你按订单制作，所有菜做好了一起上菜，然后收钱。

```
1. 顾客来到美食店 → 落座 → 系统自动请求后端点菜
   → 后端从已解锁菜谱中随机选（人数+1）道菜作为该桌订单
2. 接单 → 检查仓库有没有所需食材
   ├─ 有食材 → 直接开始烹饪
   ├─ 缺食材但有种子/有成熟作物 → 去菜园收菜 → 仓库补齐 → 开始烹饪
   └─ 缺食材且没有种子/作物 → 做不了 → 告知顾客 → 顾客离开（流失该订单）
3. 烹饪 → 汐灵可以帮忙（指派后立即完成，无需等待烹饪时间）
   → 但汐灵不在家（出去玩耍了）不能帮忙，需等它回来或手动召回
   → 饱腹度低的汐灵帮忙 → 交付时可能闯祸（打折/免单）
4. 所有菜做好 → 一起上菜给顾客
5. 顾客用餐 → 付款 → 收钱
   ├─ 正常交付 → 100% 卖价
   ├─ 汐灵闯祸 → 打7折 或 免单（取决于饱腹度档位）
```

**流程细节**：

| 步骤 | 玩家操作 | 说明 |
|------|---------|------|
| 顾客来店 | 系统自动触发 | 有空余桌子→10分钟后自动上客，每桌1~4人 |
| 顾客点菜 | **自动完成** | 后端自动从已解锁菜谱随机选（人数+1）道菜，玩家只需查看订单 |
| 检查食材 | 查看仓库 | 有→直接做；缺→去菜园收菜；没种子→做不了→客人走 |
| 开始烹饪 | 点击"开始做菜" | 每道菜按菜谱时间烹饪，可同时做多道 |
| 汐灵帮忙 | 指派汐灵 | **指派后立即完成烹饪，无需等待时间**；但汐灵不在家（出去玩/探索中）不能帮忙 |
| 上菜 | 所有菜做好后点击"上菜" | 顾客等所有菜一起上，不会一道一道吃 |
| 付款 | 自动结算 | 正常=100%卖价，闯祸=7折或免单 |

**关键设计**：
- 顾客点菜是**全自动**的——后端从已解锁菜谱中随机选（人数+1）道菜，玩家只需查看订单后决定做不做。
- 汐灵帮忙可以**立即完成烹饪**，跳过等待时间——但汐灵必须在家（在灶台旁），如果它出去玩耍了就需要等它回来或手动召回。
- 顾客等所有菜一起上，这意味着如果点了3道菜，最长的那道做完才能上菜。用汐灵帮忙可以瞬间完成，让灶台不空转。
- 如果缺食材且没有种子做不了，客人会离开——这逼玩家提前规划仓库和菜园种植。

### 1c. 菜谱表（第一期）

菜谱分 3 个等级：家常菜、特色菜、招牌菜。每种菜谱需要特定蔬菜组合。

**家常菜（Lv6 解锁）：**

| 菜谱 | 所需蔬菜 | 加工时间 | 卖价 | 利润对比 |
|------|---------|---------|------|---------|
| 清炒小白菜 | 2 小白菜 | 2min | 12 星币 | 比直接卖2个(6星币)赚2倍 |
| 胡萝卜炒蛋 | 2 胡萝卜 | 3min | 20 星币 | 比直接卖2个(16星币)赚1.25倍 |
| 番茄蛋汤 | 2 番茄 | 3min | 18 星币 | 比直接卖2个(12星币)赚1.5倍 |
| 土豆泥 | 3 土豆 | 4min | 20 星币 | 比直接卖3个(15星币)赚1.33倍 |

**特色菜（Lv8 解锁）：**

| 菜谱 | 所需蔬菜 | 加工时间 | 卖价 | 利润对比 |
|------|---------|---------|------|---------|
| 辣椒炒肉 | 2 辣椒 | 5min | 50 星币 | 比直接卖2个(40星币)赚1.25倍 |
| 玉米浓汤 | 2 玉米 | 6min | 90 星币 | 比直接卖2个(80星币)赚1.13倍 |
| 暴躁南瓜派 | 1 暴躁南瓜 | 8min | 120 星币 | 比直接卖1个(80星币)赚1.5倍 |
| 海岛蔬菜沙拉 | 1小白菜+1胡萝卜+1番茄 | 4min | 35 星币 | 比直接卖3个(17星币)赚2倍 |

**招牌菜（Lv10 解锁，需要汐灵帮忙）：**

| 菜谱 | 所需蔬菜 | 加工时间 | 卖价 | 特殊条件 |
|------|---------|---------|------|---------|
| 汐灵海鲜面 | 2番茄+1鱼(汐灵钓) | 9min | 150 星币 | 汐灵需先钓鱼 |
| 星光蔬菜煲 | 3土豆+2辣椒 | 10min | 200 星币 | 汐灵需先洗菜 |
| 海岛盛宴 | 4种不同蔬菜+1鱼 | 12min | 300 星币 | 汐灵需帮忙打水+洗菜+钓鱼 |

**关键设计：加工菜比直接卖赚更多，但需要时间+汐灵帮忙。急着要钱就直接卖给收购船，想多赚就让汐灵帮忙加工。**

**甜品（Lv7 解锁，需要汐灵探索带回的野果子）：**

甜品原料来自汐灵玩耍探索时带回的野果子，无法通过种植获得，只能在探索中获得。

| 甜品 | 所需原料 | 加工时间 | 卖价 | 来源 | 说明 |
|------|---------|---------|------|------|------|
| 🫐 野莓布丁 | 3 野莓 + 1 牛奶 | 3min | 45 星币 | 野莓=汐灵探索树林带回 | 酸甜可口，顾客超爱，回头率+10% |
| 🍑 蜜桃果冻 | 2 蜜桃 + 2 糖 | 4min | 60 星币 | 蜜桃=汐灵探索花园带回 | 晶莹剔透，好评+1，食客停留时间+5min |

**甜品特点：**
- 原料只能通过汐灵探索获得（树林出野莓，花园出蜜桃），每天数量有限
- 卖价介于家常菜和特色菜之间，但加工时间短、利润率高
- 甜品可以作为正餐之外的附加单——顾客有30%概率额外点1份甜品
- 汐灵带回野果子的数量：每次探索带回 **20 个**野果子（野莓或蜜桃随机）
- 甜品会大幅提升**好评点赞概率 80%**——顾客吃了甜品后有80%概率给你点赞好评

**好评系统：**

好评是美食店排行榜的核心指标之一。好评**仅来源于两个渠道**：

| 好评来源 | 说明 | 触发概率 |
|---------|------|---------|
| 👍 真实用户点赞 | 邻居/好友来你的美食店吃饭后，主动给你"好评"点赞 | 邻居吃完后 30% 概率点赞 |
| 🍰 甜品触发点赞 | 顾客点了甜品并吃完后，甜品好评触发 | **80% 概率**点赞 |

> **设计说明**：好评只能靠真实社交互动和甜品获得，不能花钱买、不能刷——这让好评榜成为真正反映"美食店口碑"的指标。甜品原料只能靠汐灵探索获得（每天数量有限），所以好评数量受限于探索产出，不会泛滥。想冲好评榜的玩家需要：①多加好友让邻居来吃饭（真实点赞）；②多做甜品（甜品点赞80%），两者缺一不可。

**野果子获取机制：**

| 探索地点 | 野果子类型 | 每次带回数量 | 说明 |
|---------|-----------|------------|------|
| 🌲 树林 | 🫐 野莓 | 20 个 | 树林里的野生浆果，酸甜可口 |
| 🌸 花园 | 🍑 蜜桃 | 20 个 | 花园旁野生的蜜桃，香甜多汁 |

> **设计说明**：每次汐灵去树林探索固定带回20个野莓，去花园探索固定带回20个蜜桃。这些是**珍贵食材**——不能种植、只能探索获得，给玩家做甜品提供了独特原料。加上探索带回的其他宝贝（贝壳、珍珠等），让玩耍探索的产出更加丰富。

### 1d. 游客/邻居来吃

**美食店座位配置：**

| 项目 | 说明 |
|------|------|
| 餐桌总数 | **6 张桌子** |
| 每桌人数 | 最多 **4 人**同坐 |
| 每桌来人 | 随机 1~4 人，后端自动选（人数+1）道菜 |
| 同桌同上 | 同桌所有人的菜全部做好后才一起上 |

**游客自动上客机制：**

- 有空余桌子 → **10 分钟后**自动有游客来坐，每个游客停留5分钟
- 6 张桌子全满 → 不再上客，等有桌空出来再10分钟后上新客
- 每桌客人用餐完毕 → 桌子空出 → 10 分钟计时重新开始
- 一天营业时间内持续循环，桌子永远在"等客→上客→用餐→空桌→等客"循环

**食客来源：**

| 来源 | 说明 | 付款方式 |
|------|------|---------|
| 🏖️ 岶上游客（系统NPC） | 有空桌10分钟自动来，每桌1~4人随机 | 星币 |
| 👋 邻居串门来吃 | 邻居主动点击"来一份" | 星币 + 1 友币 |
| ✨ 汐灵推荐来的食客 | 汐灵特殊能力触发（星光盛宴） | 星币 + 额外友币 |

**顾客来店后的完整流程：**
- 顾客落座 → **后端自动点菜**（从已解锁菜谱随机选人数+1道菜）→ 玩家查看订单
- 玩家检查仓库食材
  - 有食材 → 开始烹饪
  - 缺食材 → 去菜园收菜 → 仓库补齐 → 开始烹饪
  - 缺食材且没有种子 → 做不了 → 顾客离开
- 开始烹饪 → 汐灵在家？指派洗菜 → **立即完成**（+烹饪经验）
- 同桌所有菜做好 → 一起上菜 → 顾客用餐 → 付款

**邻居来吃的社交互动：**
- 邻居来你的岛串门 → 看到美食店 → 点击"来一份"
- 邻居占1桌（1人）→ 点菜 → 你做菜 → 上菜 → 付款
- 邻居来吃 → 你获得卖价星币 + 1 友币
- 吃过的邻居可以给你"好评"（类似点赞），好评数影响美食店排名（邻居点赞概率30%）

### 1f. 收购船系统

收购船是菜园蔬菜的**直接变现渠道**——不想等加工、急用钱的时候，直接把菜卖给收购船。

**收购船机制：**

| 项目 | 说明 |
|------|------|
| 出现时间 | 每天早上**首次登陆**时生成，停靠在码头 |
| 停留时间 | 当天全天有效，次日刷新 |
| 今日任务 | 随机从种子库中选择 **3 种蔬菜**作为今日高价收购任务 |
| 任务奖励 | 任务蔬菜卖价 ×2（比普通卖价高1倍） |
| 非任务蔬菜 | 按基础卖价收购（正常价格） |
| 数量限制 | 无限制，有多少收多少，统一算钱 |

**收购船示例：**

```
今日收购任务（随机3种）：
  🥬 小白菜 ×5 → 卖价6×2=12星币/个（正常3星币/个）
  🌽 玉米 ×3 → 卖价40×2=80星币/个（正常40星币/个）
  🌶️ 辣椒 ×3 → 卖价20×2=40星币/个（正常20星币/个）

非任务蔬菜（正常价收购）：
  🥕 胡萝卜 → 8星币/个
  🍅 番茄 → 6星币/个
  🥔 土豆 → 5星币/个
```

**收购船 vs 美食店的经济决策：**

| 对比 | 卖给收购船 | 送进美食店加工 |
|------|----------|-------------|
| 到手速度 | 即时到账 | 需要等顾客来+烹饪+上菜 |
| 利润 | 基础卖价（任务蔬菜×2） | 加工后卖价（通常1.2~2倍） |
| 经验 | 种菜经验 | 烹饪经验 |
| 适合场景 | 急用钱、仓库满了、任务蔬菜高价 | 想赚更多、有汐灵帮忙、不急 |

**关键设计**：收购船每天随机3种高价任务蔬菜，让玩家有动力种不同的菜。美食店加工利润更高但需要时间和汐灵配合，收购船即时变现但利润低。两条路并存，玩家根据情况自由选择。

### 1g. 种菜经验与升级系统

种菜、收菜、卖菜都会获得**种菜经验**，美食店烹饪获得**烹饪经验**，两种经验合并为玩家总经验，用于升级。

**经验获取：**

| 行为 | 经验值 | 说明 |
|------|--------|------|
| 收获蔬菜 | +2~5 经验/次 | 不同蔬菜经验不同（小白菜2，玉米5） |
| 卖菜给收购船 | +1 经验/次 | 每次卖菜（不论数量） |
| 美食店烹饪 | +3~10 经验/次 | 家常菜3，特色菜5，招牌菜10 |
| 美食店上菜收款 | +2 经验/次 | 每次完成一笔订单 |
| 喂汐灵蔬菜 | +1 经验/次 | 每次喂菜 |

**升级需求：**

| 等级 | 累计经验 | 解锁内容 |
|------|---------|---------|
| Lv1~5 | 原版设定 | 基础蔬菜种植 |
| Lv6 | 800 经验 | 开放美食店（需≥10好友+100星币+20友币） |
| Lv7 | 1200 经验 | 解锁第5块菜地 |
| Lv8 | 1800 经验 | 特色菜谱解锁 |
| Lv9 | 2500 经验 | 第6块菜地解锁 |
| Lv10 | 3500 经验 | 招牌菜谱解锁 |

**关键设计**：经验系统让收菜、卖菜、烹饪都有成长感。急卖收购船给种菜经验，加工美食给烹饪经验——两条路都能升级，不会因为选了一条路而卡等级。

## 2. 汐灵系统（岛灵）

### 2a. 汐灵是谁

**汐灵**是岛上的精灵，住在美食店的灶台旁边。它像一个淡蓝色的小水精灵，身体是流动的水珠形态，有两只亮晶晶的眼睛。

```
汐灵外观：
  - 淡蓝色半透明水珠身体
  - 两只星星形状的眼睛
  - 头上有一朵小浪花（帽子）
  - 做活时身体会变形（打水→变成水桶，钓鱼→长出鱼竿手）
  - 开心时冒出小气泡，难过时变成一小滩水
  - 闯祸时缩成一团冒汗珠，大祸时变成灰蓝色躲在灶台后面
```

汐灵有**饱腹度**和**心情**两个状态值，都是0~100：

| 状态 | 说明 | 影响什么 | 初始值 |
|------|------|---------|--------|
| 饱腹度 | 汐灵的饥饿程度 | **干活会不会闯祸、踩菜、拒绝干活** | 50（半饱） |
| 心情 | 汐灵的情绪状态 | **玩耍发现物品质、烹饪卖价加成、特殊能力触发概率** | 40（一般） |

**饱腹度与心情的关系：**

饱腹度决定心情的上限——吃饱了心情自然好，但光靠喂菜心情最多到80。想要心情100，需要**抚摸**或**夸赞**汐灵：

| 心情来源 | 心情上限 | 说明 |
|---------|---------|------|
| 喂菜恢复饱腹 | 最多到 **80** | 吃饱了心情好，但"吃饱"和"开心"不完全一样 |
| 🤲 抚摸 | 可突破80到 **100** | 每天1次，+10心情 |
| 🤗 夸赞 | 可突破80到 **100** | 回应带回宝贝时，+10心情 |
| 🎁 送礼物 | 可突破80到 **100** | +15心情 |

**心情机制：**
- 心情每 2 小时自然下降 5（比饱腹度下降慢）
- 饱腹度下降时心情跟着降——饿着肚子心情好不了
- 心情为 0 → 汐灵不想出去玩，缩在灶台旁发呆
- 喂菜时，心情同步恢复（但不超过80）
- 抚摸/夸赞/送礼物可以把心情从80推到100

**饱腹度阈值与闯祸概率：**

只有在饱腹度 **低于 40** 时汐灵才会闯祸，越饿越容易闯祸、后果越严重：

| 饱腹度 | 汐灵状态 | 闯祸概率 | 闯祸后果 | 表现描述 |
|--------|---------|---------|---------|---------|
| ≥40 | 🫧安全干活 | 0% | 无 | 身体亮晶晶，干活完美 |
| 31~39 | 🥱有点饿 | 10% | **打7折**（小祸） | 动作变慢，肚子咕咕叫 |
| 21~30 | 😣很饿了 | 30% | **打7折或免单** | 手抖脚软，眼神飘忽 |
| 11~20 | 💦快饿扁了 | 50% | **免单**（大祸） | 身体变薄变灰，走路打晃 |
| 1~10 | 🫠几乎饿死 | 80% | **免单**（大祸） | 灰蓝色一滩，随时可能趴下 |
| 0 | ❌ 拒绝干活 | — | 拒绝干活 | 变成一滩水趴在地上，说什么都不动 |

**闯祸后果规则：**
- 饱腹 31~39 → 闯祸后果固定为打7折
- 饱腹 21~30 → 闯祸后果 50%打7折 / 50%免单
- 饱腹 11~20 → 闯祸后果固定为免单
- 饱腹 1~10 → 闯祸后果固定为免单

**心情等级（影响玩耍发现品质和烹饪加成）：**

| 心情等级 | 心情值 | 汐灵表现 | 影响什么 |
|---------|--------|---------|---------|
| 🫧 开心 | 81~100 | 蹦蹦跳跳，身体亮晶晶，主动出来打招呼 | 玩耍只带回好东西及以上，稀有概率×2；烹饪卖价+10%；特殊能力触发+10% |
| 💧 正常 | 41~80 | 正常节奏干活，偶尔偷看灶台上的菜 | 玩耍正常发现；烹饪卖价+5% |
| 😣 闹脾气 | 21~40 | 动作变慢，嘟着嘴 | 玩耍只捡日常物品；烹饪无加成 |
| 🫠 低落 | 1~20 | 身体变薄变灰，走路打晃 | 玩耍几乎找不到好东西；烹饪卖价-5% |
| ❌ 不想动 | 0 | 缩在灶台旁发呆，不出去探索 | 不出去玩；无任何加成 |

### 2b. 喂汐灵蔬菜

**喂菜规则：**

| 蔬菜 | 饱腹恢复 | 心情恢复（上限80） | 说明 |
|------|---------|-----------------|------|
| 小白菜 | +15 | +5 | 最基础，汐灵勉强吃 |
| 胡萝卜 | +20 | +8 | 汐灵还算喜欢 |
| 番茄 | +25 | +10 | 汐灵喜欢酸酸甜甜 |
| 土豆 | +20 | +8 | 做成土豆泥汐灵更爱吃 |
| 辣椒 | +10 | +12 | 汐灵辣到但很开心（心情加成高） |
| 玉米 | +30 | +15 | 汐灵最爱！饱腹和心情双高 |
| 暴躁南瓜 | +50 | +20 | 稀有！汐灵吃完眼睛发光（触发特殊能力） |

> **注意**：喂菜恢复的心情最多到80。想要心情到100，需要抚摸或夸赞。

**饱腹度机制：**
- 饱腹度每 2 小时自然下降 10
- 饱腹度降到 0 → 汐灵拒绝干活，变成一小滩水躲在角落，需要喂食才能恢复
- 饱腹度 ≥ 40 → 干活安全，0%闯祸
- 饱腹度 < 40 → 干活有闯祸风险，越饿概率越高（10%→30%→50%→80%），后果越严重（7折→免单）
- 饱腹度 < 40 且不干活时 → 汐灵饿得受不了 → 会跑去菜园吃地里的菜（踩坏蔬菜减产2个，但吃完饱腹恢复至80）
- 每天至少喂 1 次，不然汐灵第二天饱腹度额外 -10

**心情机制：**
- 心情每 2 小时自然下降 5（比饱腹度慢）
- 喂菜恢复饱腹的同时恢复心情，但心情**最多到80**
- 🤲 抚摸（每天1次）→ 心情 +10，可突破80到100
- 🤗 夸赞（回应带回宝贝时）→ 心情 +10，可突破80到100
- 🎁 送礼物 → 心情 +15，可突破80到100
- 心情 ≥ 81 → 玩耍只带回好东西及以上，烹饪卖价+10%，特殊能力触发+10%
- 心情 = 0 → 汐灵不想出去玩，缩在灶台旁发呆

### 2c. 汐灵的工作（日常帮忙）

汐灵可以做 4 种日常工作，每种都有明确的游戏效果：

| 工作 | 汐灵做什么 | 正常效果 | 前置条件 |
|------|----------|---------|---------|
| 🚰 打水 | 去井边打水回来 | 所有菜地水分值恢复 30（自动浇水） | 饱腹度 ≥ 1 |
| 🧹 洗碗 | 洗美食店用过的碗盘 | 交付正常，顾客满意付款 | 美食店有出餐记录 |
| 🥬 洗菜 | 把菜洗干净备好 | **立即完成当前所有烹饪，跳过等待时间** | 美食店有菜谱在烹饪 |
| 🎣 钓鱼 | 去海边钓鱼 | 获得 1~2 条鱼（招牌菜原料） | 饱腹度 ≥ 1 |

**核心变化：汐灵帮忙 = 立即完成，无需等待烹饪时间。**

指派汐灵洗菜后，当前灶台上所有正在烹饪的菜**瞬间完成**——这是汐灵最大的价值。但有两个限制：
1. **汐灵必须在家**——如果汐灵出去玩耍/探索了，不能帮忙，需要等它回来或手动召回
2. **饱腹度低时帮忙会闯祸**——交付时触发闯祸判定（见2d）

**干活只看饱腹度。** 饱腹度 ≥ 40 时干活完美（0%闯祸）；饱腹度低时干活有闯祸风险——闯祸只在给顾客交付美食时体现。

**工作触发方式：**

**方式 1：手动指派**
- 打开美食店 → 点击汐灵 → 选择"今天帮我做什么"
- 每天可指派 **2 项工作**
- 指派前系统提示："汐灵饱腹度35，心情72。帮忙立即完成但交付时10%概率打7折，建议先喂菜"
- 如果汐灵不在家（出去玩了），提示："汐灵出去玩了！等它回来或手动召回才能帮忙"

### 2d. 汐灵闯祸机制

**核心规则：闯祸只在给顾客交付美食时体现，不影响制作流程。**

汐灵饿着干活时，烹饪照样做、时间照样跑。闯祸只在**上菜给顾客**的时候体现——碗碎了、菜里有沙子，顾客不满意，后果是**经济惩罚**：

**闯祸概率与后果（饱腹度 < 40 才闯祸）：**

| 饱腹度 | 闯祸概率 | 闯祸后果 | 交付表现 | 玩家收入 |
|--------|---------|---------|------------|---------|
| ≥40 | 0% | 无 | 美食端上桌，顾客满意 | **100% 卖价** |
| 31~39 | 10% | 小祸 | 碗有裂纹/菜里有沙子，顾客不太满意 | **70% 卖价** |
| 21~30 | 30% | 小祸或大祸 | 50%打7折，50%免单 | **35%或0%** |
| 11~20 | 50% | 大祸 | 碗碎了溅一身/菜里有虫子，顾客很不满 | **0% 卖价** |
| 1~10 | 80% | 大祸 | 同上 | **0% 卖价** |
| 0 | — | 拒绝干活 | 不干活 | 不影响 |

**小祸叙事：**

| 工作 | 小祸内容 | 顾客反应 |
|------|---------|---------|
| 洗碗 | 碗边有裂纹，汤汁渗出来了 | "碗有点裂缝……味道还行，给7折吧" |
| 洗菜 | 菜叶上还沾着沙子 | "怎么菜里还有沙子？不太满意，打7折吧" |
| 打水 | 水溅到了灶台上，菜品味道略淡 | "味道好像淡了一点……打7折吧" |
| 钓鱼 | 鱼不够新鲜（饿着钓效率低） | "这鱼好像不够新鲜……打7折吧" |

**大祸叙事：**

| 工作 | 大祸内容 | 顾客反应 |
|------|---------|---------|
| 洗碗 | 碗碎了，汤汁溅到顾客身上！ | "我的衣服！这顿免单吧！" |
| 洗菜 | 菜里混了泥和虫子，根本没法吃 | "这菜里有虫！免单！我再也不来了！" |
| 打水 | 水桶翻了，冲进了灶台，整锅汤糊了 | "这汤糊了……免单吧" |
| 钓鱼 | 鱼竿断了鱼跑了，招牌菜缺鱼 | "说好的海鲜面呢？免单！" |

**闯祸对收入的影响——以招牌菜为例**：

以「海岛盛宴」为例（卖价300星币）——高价值菜品闯祸惩罚大：

| 饱腹度 | 闯祸概率 | 正常收入 | 小祸收入(70%) | 大祸收入(0%) | 期望收入 |
|--------|---------|---------|-------------|-------------|---------|
| ≥40 | 0% | 300 | — | — | **300 星币** |
| 31~39 | 10% | 300 | 210 | — | **291 星币**（90%正常+10%7折） |
| 21~30 | 30% | 300 | 210 | 0 | **241.5 星币**（70%正常+15%7折+15%免单） |
| 11~20 | 50% | 300 | — | 0 | **150 星币**（50%正常+50%免单） |
| 1~10 | 80% | 300 | — | 0 | **60 星币**（20%正常+80%免单） |

以「清炒小白菜」为例（卖价12星币）——低价值菜品闯祸损失小：

| 饱腹度 | 闯祸概率 | 期望收入 | 闯祸最大损失 |
|--------|---------|---------|------------|
| ≥40 | 0% | **12 星币** | 0 |
| 31~39 | 10% | **11.64 星币** | 亏3.6星币 |
| 21~30 | 30% | **10.14 星币** | 亏6.3星币 |
| 11~20 | 50% | **6 星币** | 亏12星币 |
| 1~10 | 80% | **2.4 星币** | 亏12星币 |

**设计意图**：闯祸门槛从40开始，越饿越严重。概率比之前更温和（10%起步），卖家常菜饿着干最多亏几星币，卖招牌菜饿着干期望值也有241星币（饱腹21~30档）。但饱腹<20后惩罚陡增，卖招牌菜前还是要喂菜。

**闯祸后的汐灵反应：**

| 闯祸程度 | 汐灵动画 | 汐灵台词 | 玩家感受 |
|---------|---------|---------|---------|
| 小祸（7折） | 缩成一团，冒小汗珠 | "对不起……碗边好像有点裂……" | 丢了30%收入，下次喂饱就好 |
| 大祸（免单） | 变成灰蓝色，躲在灶台后面 | "我……我把碗摔碎了……你别生气……" | 整份白做！心疼+想赶紧喂它 |
| 连续闯祸（当天第2次） | 变成一小滩水，头上冒泪珠 | "我做不到……让我休息好不好……" | 决定不逼它了 |

**连续闯祸规则**：当天累计闯祸2次 → 汐灵拒绝继续干活（趴在灶台旁不动），必须喂菜恢复饱腹度到 ≥40 才能再指派。

### 2e. 汐灵踩坏蔬菜（饿到去菜园吃菜）

饱腹度 < 40 的汐灵如果不干活（未被指派工作），饿得受不了会跑去菜园直接吃地里的菜——吃相不好把菜地踩坏了。**出来后饱腹度恢复至 80**（吃饱了！）。

**踩菜机制：**

| 触发条件 | 说明 |
|---------|------|
| 饱腹度 < 40 | 汐灵饿得受不了，想找吃的 |
| 今天没有被指派工作 | 没活干+饿着→汐灵跑去菜园找菜吃 |
| 指派工作完成后的空闲时间 | 饿着干完活→剩余时间饿到去菜园吃菜 |

**踩菜后果：**

| 项目 | 说明 |
|------|------|
| 踩菜频率 | 每次踩坏 **1块菜地** |
| 踩菜损失 | 该菜地产量 **减产2个**（原本收5个变3个） |
| 饱腹恢复 | **踩菜后饱腹度恢复至 80**（汐灵吃地里的菜吃饱了！） |
| 踩菜动画 | 汐灵饿得摇摇晃晃跑进菜园 → 扑到菜地上啃菜 → 菜苗被压歪 → 吃饱后满足地拍拍肚子 → "呼~终于不饿了！" |
| 每天上限 | 最多踩坏 **2块地/天** |
| 被踩的菜地 | 随机选择一块成熟度最高的菜地（汐灵看到成熟的菜更想吃） |

**如何防止踩菜：**

| 方法 | 说明 |
|------|------|
| 喂菜恢复饱腹 ≥ 40 | 最根本的解决方式——不饿就不会去吃地里的菜 |
| 指派汐灵干活 | 有活干就不去吃菜（即使饿着也先干活） |
| 补饭机（满级版） | 饱腹永远100，永远不会饿到去菜园吃菜 |

**踩菜通知：**

- 踩菜发生后，菜园界面弹出提示："汐灵饿得受不了跑去菜园吃菜了！XX菜地被踩坏，产量减少2个。但它吃饱了（饱腹度恢复至80）。记得按时喂它蔬菜！"
- 汐灵踩完吃完后回到灶台，摸着圆滚滚的肚子："……好饱……但你下次早点喂我嘛，地里的菜没有你喂的好吃……"

### 2f. 汐灵的玩耍探索（不干活时）

汐灵不是永远在干活的机器。没有被指派工作时，它会在岛上各处玩耍探索，偶尔捡到宝贝带回来。**更重要的是，汐灵出去玩还会带回珍贵食材——这些食材无法通过种植获得，只能靠探索获取。**

**玩耍触发条件：**

| 条件 | 说明 |
|------|------|
| 今天没有指派任何工作 | 汐灵全天出去玩耍 |
| 指派的工作完成后 | 剩余时间出去玩（半天玩耍） |
| 汐灵拒绝干活（饱腹度=0） | 也出去玩耍——但它只想躺在沙滩上晒太阳 |
| 汐灵被闯祸停工（当天闯祸2次） | 离开灶台去外面玩，心情低落 |

**玩耍时间机制**：
- 全天玩耍 → 上午和下午各探索1个地点（共2次发现）
- 半天玩耍 → 探索1个地点（1次发现）
- 饿着/委屈玩耍 → 只探索1个地点，发现品质下降

**玩耍地点与发现物：**

汐灵会随机选择探索地点，不同地点有不同的发现物池：

**🏖️ 海边沙滩**（最常去，40%概率）

| 发现物 | 概率 | 用途 |
|--------|------|------|
| 贝壳（1~3个） | 80% | 美食店装饰（好评+2%）或卖3星币 |
| 海星 | 30% | 花园装饰（花香联动+1食客） |
| 珍珠 | 10%（心情≥81→15%） | 送汐灵礼物/美食店高级装修 |
| 漂流瓶 | 15% | 打开获得：随机小任务/一首小诗/一张旧地图碎片 |
| 彩虹贝壳 | 5%（心情≥81→10%） | 美食店豪华装饰（好评+10%） |

**🌿 菜园旁**（25%概率）

| 发现物 | 概率 | 用途 |
|--------|------|------|
| 稀有种子碎片 | 25% | 5碎片=1个暴躁南瓜种子 |
| 蚯蚓 | 40% | 钓鱼下次产出+1（鱼爱吃蚯蚓） |
| 小石头 | 50% | 无用但汐灵觉得好看（收藏品） |
| 偶尔发现的野菜 | 15% | 1个随机蔬菜（白赚！） |
| 精灵花粉 | 8%（心情≥81→12%） | 可制作"精灵蜜"（喂汐灵饱腹+40） |

**🌲 树林里**（20%概率）

| 发现物 | 概率 | 用途 |

### 3f. 好友系统

好友系统是美食店、偷菜、串门等社交玩法的基础。玩家通过系统推荐添加好友，成为好友后可以互相访问主页、偷花、捉虫等。

**加好友机制：**

| 步骤 | 说明 |
|------|------|
| 1. 点击"添加好友" | 系统自动推荐 **20 个用户**（基于等级相近、活跃度相似推荐） |
| 2. 浏览推荐列表 | 查看对方昵称、等级、岛名、在线状态 |
| 3. 点击"添加" | 发送好友请求，对方同意后成为好友 |
| 4. 成为好友后 | 可互相访问主页、进入对方岛屿互动 |

**推荐规则：**
- 优先推荐等级±3以内的活跃玩家
- 推荐列表每天刷新一次
- 已发送请求但未同意的不重复推荐
- 好友上限：100人

**好友互动功能：**

| 互动 | 说明 | 消耗/奖励 |
|------|------|----------|
| 🏠 串门访问 | 进入好友岛屿，看到对方的菜园/花园/美食店 | 免费 |
| 🌸 偷花 | 在好友花园偷1朵花（每天每好友限偷1次） | 获得1朵花，好友损失1朵 |
| 🐛 捉虫 | 在好友菜园帮忙捉虫（每天每好友限1次） | 好友菜地除虫+1，自己获得1友币 |
| 💧 浇水 | 在好友菜园帮忙浇水 | 好友菜地水分+20，自己获得1友币 |
| 🍽️ 去好友美食店吃饭 | 邻居串门来吃反向操作——你去好友店吃饭 | 花星币，好友赚星币+好评 |
| 📝 留言 | 在好友主页留言板留言 | 免费 |
| 🎁 送菜 | 给好友送蔬菜 | 消耗蔬菜，好友获得蔬菜 |

**偷花机制细节：**
- 每天每人最多被偷3朵花（防止被偷光）
- 偷花有30%概率被发现 → 被发现后好友收到通知"XX来偷了你的花！"
- 未被发现 → 安静偷走，好友不知道
- 好友偷花被发现后 → 好友收到通知"XX来偷了你的花！"，可以回访"报复"

**好友与美食店的联动：**
- 开美食店需要≥10好友
- 好友可以来你的美食店吃饭 → 你赚星币+友币+好评
- 好友数量影响美食店排行榜权重（好友越多人气越高）
- 好友的好评可以提升美食店排名

### 3g. 每日心情与心情日记

每天玩家可以记录自己的心情，不同心情会在美食店周围长出不同的小花，形成独特的**心情日记**。

**心情记录机制：**

| 项目 | 说明 |
|------|------|
| 记录时间 | 每天早上首次登陆时记录（与写日记同步） |
| 心情类型 | 😊开心 / 😌平静 / 😢难过 / 🤔期待 / 😤生气 / 🥰幸福 |
| 每日1次 | 每天只能记录1次，记录后不可更改 |
| 心情花 | 根据当天心情，美食店周围自动长出对应颜色的小花 |

**心情与花朵对应：**

| 心情 | 花朵颜色 | 花朵数量 | 说明 |
|------|---------|---------|------|
| 😊 开心 | 🌼 黄色小雏菊 | 3朵 | 阳光般温暖 |
| 😌 平静 | 🤍 白色满天星 | 2朵 | 安静柔和 |
| 😢 难过 | 💙 蓝色勿忘我 | 1朵 | 一朵就够了 |
| 🤔 期待 | 🌸 粉色樱花 | 2朵 | 充满希望 |
| 😤 生气 | 🔴 红色玫瑰 | 1朵 | 带刺的 |
| 🥰 幸福 | 🌈 彩虹花 | 5朵 | 最美的心情开最美的花 |

**心情花的作用：**
- 美食店周围的花越多 → 食客吸引力 +1~3（花香吸引人）

**心情日记：**

心情日记是一个独立界面，记录玩家每天的心情和当天发生的事：

| 日记字段 | 说明 |
|---------|------|
| 日期 | 自动记录 |
| 心情emoji | 玩家选择的心情 |
| 心情花 | 当天长出的花（自动生成） |
| 一句话 | 玩家可输入一句话（可选，最多50字） |
| 当天大事 | 系统自动记录：卖出XX份美食、汐灵触发XX能力、升级到LvX等 |
| 天气 | 当天岛上的天气（自动记录） |

**心情日记示例：**

```
📅 2026年7月22日 星期三 ☀️ 晴

😊 心情：开心

📝 一句话：今天汐灵第一次带回珍珠了！好开心！

📌 今日大事：
  · 美食店卖出8份美食
  · 汐灵触发「潮汐祝福」
  · 升级到 Lv7！解锁甜品菜谱
  · 收购船高价收购：玉米×3
```

**心情日记的社交功能：**
- 好友可以访问你的主页查看你的心情日记（最近7天）
- 好友可以给你的心情日记"送花"（类似点赞）
- 收到好友送花 → 汐灵心情+1（被认可的感觉）

**心情与游戏机制的联动：**

## 5. 广告福利系统

广告福利是零氪玩家的好帮手——看一段短视频广告，获得限时增益或免费服务。

### 5a. 双倍金币 & 双倍经验（3小时）

看广告后获得**双倍金币和双倍经验**buff，持续3小时。

| 项目 | 说明 |
|------|------|
| 触发方式 | 主界面点击"看广告领福利" → 选择"双倍收益" |
| 广告时长 | 15~30秒 |
| buff效果 | **金币×2 + 经验×2**，持续 **3 小时** |
| 影响范围 | 卖菜给收购船、卖美食、收菜经验、烹饪经验、喂菜经验——全部翻倍 |
| 每日上限 | **2 次/天**（最多6小时双倍） |
| 叠加规则 | 不与活动双倍叠加（取最高倍率） |
| 到期提醒 | 剩余10分钟时弹窗提醒"双倍buff快结束了！" |

**双倍收益举例：**

| 行为 | 正常收益 | 双倍收益 | 说明 |
|------|---------|---------|------|
| 卖菜给收购船（任务蔬菜玉米×3） | 240星币 + 1经验 | **480星币 + 2经验** | 金币经验双翻 |

| 收菜（玉米×5） | 0星币 + 5经验 | **0星币 + 10经验** | 经验翻倍 |
| 喂汐灵蔬菜 | 0星币 + 1经验 | **0星币 + 2经验** | 小收益也翻倍 |

**最佳使用时机：**
- 收购船有高价任务蔬菜时 → 攒一波菜 → 开双倍 → 全卖给收购船
- 美食店排队人多时 → 开双倍 → 连续做菜上菜
- 汐灵触发特殊能力（烈焰潮汐卖价×3）时 → 叠加双倍 → 利润×6

看广告获得满级补饭机免费体验，详见 [2h节](#2h-汐灵自动补饭机)。

| 项目 | 说明 |

| 广告时长 | 15~30秒 |

| 效果 | 饱腹100、心情100、0%闯祸、100%触发能力、幸运拉满、带回2种食材 |
| 每日上限 | **2 次/天**（最多6小时免费） |
| 叠加规则 | 与付费订阅叠加时，优先消耗免费时长 |

### 5c. 广告福利一览

| 福利 | 每日上限 | 单次时长 | 效果 |

## 11. 设计理念

**美食店解决的核心问题：** 种菜→卖菜太单调。顾客自动点菜（后端随机选人数+1道菜）→检查食材→做菜→汐灵帮忙立即完成→上菜→收钱，这个流程让玩家有了真正的经营手感。食材不够要去收菜，汐灵不在家要等或召回，闯祸了顾客打折/免单。这给了玩家**经营决策感**。

**好评系统解决的核心问题：** 排行榜不能靠刷。好评**仅来源于两个渠道**——邻居来吃饭后真实点赞（30%概率）和顾客吃甜品后触发点赞（80%概率）。好评不能花钱买、不能刷量，只能靠社交互动和甜品获得。甜品原料只能靠汐灵探索（每天数量有限），所以好评数量受探索产出限制——想冲好评榜的玩家必须同时经营好友关系和探索产出，这让好评榜成为真正反映"美食店口碑"的指标。

**收购船+双路径解决的核心问题：** 收获的菜既能即时卖给收购船（快钱+种菜经验），又能送进美食店加工（高利润+烹饪经验）。收购船每天随机3种高价任务蔬菜，让种菜有方向感。两条路都能获得经验升级，不会因为选了一条路而卡等级。

**汐灵闯祸解决的核心问题：** 汐灵不是完美的工具人——饿了干活会闯祸，碗碎了顾客免单。低于40才闯祸，概率从10%到80%递增，越饿越严重。这制造了**风险决策**：卖家常菜饿着干最多亏几星币，卖招牌菜饿着干期望值也有241星币（饱腹21~30档）。

**汐灵踩菜解决的核心问题：** 饿着不干活不只是"没帮忙"——汐灵饿得受不了会跑去菜园直接吃地里的菜，踩坏蔬菜减产2个/块地（吃完饱腹恢复至80）。这让**忽略汐灵饥饿**有了双重代价：干活闯祸亏钱，不干活踩菜亏菜。但踩菜后饱腹恢复至80也算汐灵的"自救"——不会一直饿死，给玩家一个缓冲。逼玩家必须管汐灵吃饭。

**汐灵玩耍+珍贵食材解决的核心问题：** 不干活时汐灵没有存在感。玩耍探索系统让汐灵不在干活也有产出——每次固定带回20个珍贵食材（野莓/蘑菇/木耳/蜜桃/小鱼干），加上随机发现物（贝壳、珍珠等），让日常操作多了**期待感**（"今天汐灵出去玩了，晚上会带什么回来？"）。野果子做甜品（野莓布丁45星币/蜜桃果冻60星币）让探索产出直接转化为收入。

**好友系统解决的核心问题：** 种菜经营太孤独。好友系统让玩家有社交连接——推荐20人加好友、互相串门、偷花捉虫浇水、去好友美食店吃饭。偷花有30%被发现概率增加了**互动乐趣**，好友来吃饭给友币+好评让社交直接反哺经营。开美食店需≥10好友，让经营有社交门槛。

**每日心情与心情日记解决的核心问题：** 游戏缺少每日仪式感和情感记录。每天选心情→美食店周围长出对应颜色的小花→心情日记自动记录当天大事，让每一天都有**独一无二的痕迹**。心情还影响烹饪加成（开心+10%、幸福汐灵饱腹+5），连续记录解锁装饰和成就，好友可以查看和送花——让心情记录有社交价值。

**满级补饭机解决的核心问题：** 不是所有玩家都有时间每天上线管汐灵。满级补饭机3元/月，饱腹永远100、心情永远100、闯祸永远0%、特殊能力100%触发、玩耍幸运拉满带回2种食材——让没时间的玩家也能享受**满级汐灵体验**。但亲手喂菜的互动体验是补饭机替代不了的，付费买的是省心不是替代陪伴。

**心情系统解决的核心问题：** 饱腹度管"能不能干活"，心情管"干得好不好"。喂菜把心情推到80，但想要100必须额外抚摸或夸赞——这让玩家和汐灵的**互动有了明确价值**。心情100时玩耍只带回好东西、烹饪卖价+10%、特殊能力触发+10%，让"摸一摸汐灵"不只是一个动画，而是实打实的收益。

**广告福利解决的核心问题：** 零氪玩家也需要福利出口。看15秒广告获得3小时双倍金币经验、或3小时满级补饭机体验，每天各2次——让零氪玩家每天有6小时满级体验+6小时双倍收益。3元/月补饭机面向"不想每天看广告"的玩家，广告福利面向"不想花钱"的玩家，各取所需。

**一句话：双路径让种菜有选择，收购船让快钱有去处，经验让成长有反馈，美食店让经营有手感，甜品80%触发好评让口碑有来源（好评只靠邻居点赞+甜品，不能刷），汐灵帮忙立即完成让等待有解法，饱腹度管干活闯祸踩菜（饿到去菜园吃菜减产2个但吃完饱腹恢复80），心情管玩耍运气和烹饪加成——喂菜到80，抚摸夸赞到100——满级补饭机3元全托管或看广告免费体验3h，广告双倍收益3h让零氪也有福利，但亲手喂的才真香。**
