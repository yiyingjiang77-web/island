# 海岛日记 — 分阶段开发拆分方案

## 核心理念

**从一块菜地开始，逐步长成温馨小镇。**

玩家初始拥有一片森林中的小屋、一块菜地、一条小河。周围全是树。通过种菜升级，达到对应等级后花钱砍树，解锁新区域、建造新模块，最终把荒岛变成一个有菜园、花园、美食店、沙滩、码头的温馨小镇。

---

## 地图扩张机制

### 砍树解锁系统

| 要素 | 说明 |
|------|------|
| 初始地图 | 小屋 + 1块菜地 + 小河，四周被树林包围 |
| 砍树条件 | 达到对应等级 + 消耗星币（砍树费） |
| 砍树效果 | 树林消失 → 该区域解锁 → 可建造/使用新功能 |
| 视觉表现 | 砍树前：密集树林遮挡（显示"需要LvX解锁"）；砍树后：区域展开，新建筑/地块出现 |
| 砍树动画 | 玩家点击树林 → 消耗星币 → 砍树动画（树倒下）→ 区域展开 |

| 顺序 | 区域 | 解锁等级 | 砍树费 | 解锁内容 |
|------|------|---------|--------|---------|

| 2 | 日记小屋 | Lv3 | 80星币 | 日记系统、心情记录 |
| 3 | 菜地扩展区 | Lv4 | 120星币 | 第3、4块菜地 |

| 10 | 岩石区 | Lv10 | 500星币 | 矿石、宝石、升级材料 |

## 开发阶段拆分

### P0 — 种菜MVP（绝对最小可玩版本）

**目标**：验证"种菜→收菜→卖菜→买种子"核心循环是否有趣。

**地图**：
```
🌲🌲🌲🌲🌲🌲
🌲          🌲
🌲  🏠  🌱  🌲
🌲  🌊🌊🌊  🌲
🌲          🌲
🌲🌲🌲🌲🌲🌲
```

**包含内容**：

| 模块 | 内容 |
|------|------|
| 地图场景 | 小屋 + 1块菜地 + 小河 + 四周树林（不可交互） |
| 种菜系统 | 买种子→播种→浇水→等待→收菜，5种基础蔬菜 |
| 仓库 | 存放蔬菜和种子 |
| 货币 | 星币（初始给500） |
| 等级 | Lv1~5，收菜获得经验升级 |
| 卖菜 | 每天早上一艘收购船来收菜（简单版：固定价格收购） |
| 种子商店 | 简单UI：花星币买种子 |

**蔬菜品种（P0）**：

| 蔬菜 | 解锁等级 | 生长时间 | 买种子 | 卖价 |
|------|---------|---------|--------|------|
| 小白菜 | Lv1 | 2h | 2星币 | 3星币 |
| 胡萝卜 | Lv1 | 4h | 5星币 | 8星币 |
| 番茄 | Lv2 | 6h | 4星币 | 6星币 |
| 土豆 | Lv3 | 8h | 3星币 | 5星币 |
| 辣椒 | Lv4 | 12h | 10星币 | 20星币 |

**核心循环**：
```
买种子 → 种菜 → 浇水 → 等待生长 → 收菜 → 卖给收购船 → 赚星币 → 买种子
                                          → 获得经验 → 升级 → 解锁新蔬菜
```

**不包含**：日记、好友、花园、美食店、汐灵、沙滩、心情系统、任务系统、装修。

**验收标准**：玩家能完成"种菜→收菜→卖菜→买种子"完整循环，有动力持续玩3天以上。

### P1 — 菜地扩展 + 砍树机制

**目标**：建立"升级→砍树→解锁新区域"的扩张骨架，让玩家有成长目标。

**新增内容**：

| 模块 | 内容 |
|------|------|
| 砍树系统 | 达到等级+花星币→砍树→解锁新区域（核心扩张机制） |
| 菜地扩展 | Lv2砍树→第2块地，Lv4砍树→第3、4块地，Lv9砍树→第5、6块地 |
| 更多蔬菜 | 玉米(Lv5)、暴躁南瓜(Lv8稀有) |
| 经验系统 | 收菜/卖菜给经验，经验升级解锁新内容 |
| 水分系统 | 每块地有水分值，每4h-10，需浇水 |
| 除虫系统 | 随机长虫，需手动除虫 |
| 每日任务 | 简单的每日小确幸（收3次菜、浇5次水等） |
| 收购船升级 | 每天随机3种高价任务蔬菜（卖价x2） |

**等级解锁表（P0+P1）**：

| 等级 | 累计经验 | 解锁内容 |
|------|---------|---------|
| Lv1 | 0 | 初始：小屋+1块菜地+小白菜/胡萝卜 |
| Lv2 | 100 | 砍树→第2块菜地 + 番茄种子 |
| Lv3 | 250 | 砍树→日记小屋区域 + 土豆种子 |
| Lv4 | 450 | 砍树→第3、4块菜地 + 辣椒种子 + 好友码头区域 |
| Lv5 | 700 | 砍树→花园 + 玉米种子 |

**验收标准**：玩家有明确的升级目标，砍树解锁新区域带来成就感，菜地从1块扩展到4块。

---

### P2 — 日记 + 心情系统

**目标**：加入情感内核，让游戏不只是种菜工具，而是情绪治愈空间。

**新增内容**：

| 模块 | 内容 |
|------|------|
| 日记小屋 | Lv3砍树解锁，进入小屋写日记 |
| 心情标签 | 8种基础心情（开心/平静/感动/思念/期待/难过/焦虑/生气） |
| 心情加成 | 不同心情影响种植（开心+10%速度、生气触发暴躁南瓜等） |
| 心情花 | 写日记后菜地旁长出对应心情的花 |
| 日记本 | 回顾历史日记，按日期/心情筛选 |

**心情与种植加成**：

| 心情 | 加成效果 |
|------|---------|
| 开心 | 生长速度+10% |
| 平静 | 无特殊加成，最稳定 |
| 期待 | 下次收获产量+5% |
| 难过 | 收获时额外掉1朵心情花 |
| 生气 | 有概率触发暴躁南瓜（卖价翻倍） |
| 焦虑 | 树林寻宝贝壳概率+15%（P4沙滩解锁后生效） |

**验收标准**：玩家每天有动力写日记，心情选择影响种植策略，形成"写日记→选心情→影响种菜"的循环。

---

### P3 — 社交好友系统

**目标**：打破单机体验，建立社交连接，为美食店（需10好友）做铺垫。

**新增内容**：

| 模块 | 内容 |
|------|------|
| 好友码头 | Lv4砍树解锁 |
| 好友推荐 | 系统推荐20个等级相近的玩家 |
| 添加好友 | 发送请求→对方同意→成为好友 |
| 串门访问 | 进入好友岛屿，看对方的菜园/小屋 |
| 偷菜 | 偷好友的菜（不损失作物，双方都获友币） |
| 浇水互助 | 帮好友浇水，自己获友币 |
| 捉虫互助 | 帮好友捉虫，自己获友币 |
| 友币系统 | 新货币：社交互动获得，用于稀有种子等 |
| 留言板 | 在好友主页留言 |

**友币用途**：
- 收菜时触发"稀有品种"弹窗，花50友币收获
- 后续P5美食店装修需要友币
- 好友数量是P5开美食店的前置条件（需>=10好友）

**验收标准**：玩家有3个以上好友，每天有串门互动的动力，友币有消费出口。

### P4 — 花园 + 沙滩

**目标**：丰富日常活动，增加收集和探索乐趣。

**新增内容**：

| 模块 | 内容 |
|------|------|
| 花园 | Lv5砍树解锁，种花（中周期，天级） |
| 花的种类 | 向日葵/雏菊/玫瑰/薰衣草等，对应不同心情花色 |
| 花香联动 | 花园绽放的花越多→美食店食客+1~3（P5解锁后生效） |
| 沙滩 | Lv7砍树解锁，捡贝壳 |
| 贝壳品级 | 小白贝/粉色扇贝/金色扇贝/紫色海螺 |
| 开珍珠 | 打开贝壳获得珍珠（品级越高珍珠越多） |
| 珍珠商店 | 珍珠兑换：加速肥料/稀有种子盲盒/珍珠限定装扮/珍珠→星币(1:10) |
| 宠物 | 猫/狗/兔三选一，纯陪伴，在家和花园走动 |

**验收标准**：玩家每天除了种菜还有花可种、贝壳可捡，收集系统让玩家有长期目标。

### P5 — 美食店 + 汐灵系统

**目标**：引入经营玩法和精灵伙伴，游戏从"种菜卖菜"升级为"种菜→加工→经营"。

**前置条件**：玩家需达到Lv6 + 拥有>=10好友 + 100星币 + 20友币。

**新增内容**（对应 `island-v1.md` 全部内容）：

| 模块 | 内容 |
|------|------|
| 美食店建造 | Lv6砍树→花300星币+100星币+20友币建造 |
| 菜谱系统 | 家常菜(Lv6)/特色菜(Lv8)/招牌菜(Lv10)/甜品(Lv7) |
| 出餐流程 | 顾客自动来→自动点菜→检查食材→烹饪→汐灵帮忙立即完成→上菜→收款 |
| 汐灵系统 | 饱腹度+心情双状态值，喂菜/抚摸/夸赞 |
| 闯祸机制 | 饱腹<40干活闯祸（7折/免单），只在交付时体现 |
| 踩菜机制 | 饱腹<40不干活时饿到去菜园吃菜（减产2个，吃完饱腹恢复80） |
| 玩耍探索 | 不干活时出去玩，带回宝贝+珍贵食材 |
| 特殊能力 | 喂稀有蔬菜触发限时buff |
| 好评系统 | 好评仅来自邻居点赞(30%)+甜品点赞(80%)，不能刷 |
| 收购船升级 | 收购船停靠沙滩码头，每天3种高价任务蔬菜 |

**汐灵双状态**：
- 饱腹度(0~100)：管干活闯祸/踩菜/拒绝干活
- 心情(0~100)：管玩耍发现品质/烹饪加成/特殊能力触发

**验收标准**：玩家能经营美食店赚钱，汐灵成为情感伙伴，种菜→加工→经营的完整链路打通。

## 阶段依赖关系

```
P0 种菜MVP
  └─→ P1 菜地扩展+砍树（需要等级系统）
        ├─→ P2 日记心情（需要等级解锁日记小屋）
        │     └─→ P3 社交好友（需要等级解锁好友码头）
        │           └─→ P4 花园沙滩（需要等级+社交基础）
        │                 └─→ P5 美食店+汐灵（需要>=10好友+花园联动）
        │                       └─→ P6 深度玩法（需要美食店+汐灵基础）
        │                             └─→ P7 探索岛（需要完整主岛体验）
```

**关键依赖**：
- P3好友系统是P5美食店的前置（需>=10好友才能开店）
- P4花园是P5美食店的联动（花香吸引食客）
- P2心情系统是P5汐灵心情状态的基础
- P1砍树机制是所有后续区域解锁的基础框架

## MVP (P0) 最小功能清单

只做以下内容，其他全部不做：

### 必须做
- [ ] 地图场景：小屋 + 1块菜地 + 小河 + 四周树林背景
- [ ] 种菜：5种蔬菜（小白菜/胡萝卜/番茄/土豆/辣椒）
- [ ] 种菜流程：买种子→播种→浇水→等待→收菜
- [ ] 仓库：存蔬菜和种子
- [ ] 星币：初始500，卖菜获得，买种子消耗
- [ ] 经验等级：Lv1~5，收菜给经验
- [ ] 收购船：每天来一次，固定价格收菜
- [ ] 种子商店：花星币买种子

### 不做（留给后续阶段）
- 日记/心情（P2）
- 好友/社交（P3）
- 花园/沙滩/宠物（P4）
- 美食店/汐灵/烹饪（P5）
- 排行榜/装修/故事线/补饭机/广告（P6）
- 探索岛/NPC/划船（P7）
