# 海岛日记 - 游戏主页视觉设计规范

> 最后更新: 2026-07-25

## 一、整体风格定位

| 维度 | 描述 |
|------|------|
| 视角 | 斜45度俯视（isometric 2.5D） |
| 画风 | Q版可爱田园经营 |
| 氛围 | 治愈、温馨、安静、童话、放松 |
| 参考风格 | 类似《牧场物语》《星露谷物语》的Q版简化版 |
| 地图模式 | 开放式大地图，支持上下左右拖动查看，场景边缘自然延展 |

## 二、配色方案

| 色彩角色 | 色值参考 | 用途 |
|----------|----------|------|
| 奶油白 | #FFF8E7 | 背景/天空底色 |
| 暖黄色 | #F4D35E | 茅草屋顶/灯光/UI高亮 |
| 浅紫色 | #C5A3D6 | 花丛/装饰/神秘感元素 |
| 草绿色 | #7EC850 | 草地/树叶/自然元素 |
| 木棕色 | #B8865B | 建筑/栅栏/桥梁/路径 |
| 天蓝色 | #87CEEB | 河流/水塘 |
| 樱花粉 | #FFB7C5 | 樱花树/装饰花 |
| 整体色调 | 低饱和度 | 软萌治愈风，避免高对比刺眼 |

### 光影规则
- 柔和夜间光影 + 温暖阳光
- 无硬阴影，使用柔和的半透明阴影
- 梦幻氛围，边缘轻微柔化

## 三、场景分层（Z轴深度）

### 远景层
- 森林边缘（密集树木轮廓）
- 天空渐变（奶油色到浅蓝）
- 远山轮廓（半透明，营造深度感）
- **设计要求**: 玩家拖动时远景移动速度最慢（视差效果）

### 中景层
- 茅草屋（核心建筑）
- Q版角色
- 樱花树、大型灌木
- 石板小路
- 庭院装饰（花丛、陶罐）
- **设计要求**: 玩家拖动时中景正常速度移动

### 近景层
- 16宫格菜地
- 小河 + 木桥 + 小水塘
- 篱笆、石块、小花
- 小鸭子、南瓜等小物件
- **设计要求**: 玩家拖动时近景移动速度最快

## 四、场景元素清单

### 4.1 茅草屋（核心建筑）
- 材质：茅草屋顶 + 木质门窗
- 尺寸：约占屏幕中景区域的 1/4
- 位置：屏幕中偏右
- 交互：点击可进入屋内（后续版本）/ 显示房屋信息
- 门前的石板小路连接到菜地

### 4.2 16宫格菜地（核心玩法区域）
- 位置：屏幕左下角
- 样式：4x4 网格，每格可独立种植
- 土壤纹理：深棕色耕地质感，带有细小颗粒
- 周围装饰：木质篱笆围合、石块点缀、小花环绕
- 交互：点击空格 → 种子选择面板；点击作物 → 浇水/收获
- 状态显示：每格上方显示作物成长进度条

### 4.3 Q版角色
- 比例：头大身小（头身比约 1:1.5）
- 外观：深色长发 + 小花发夹 + 浅色衣服
- 位置：站在茅草屋附近
- 动画：待机微晃、走路弹跳、干活弯腰
- 交互：点击角色 → 对话/心情显示

### 4.4 自然景观
| 元素 | 位置 | 说明 |
|------|------|------|
| 小河 | 菜地与房屋之间 | 蜿蜒流过，有木桥跨越 |
| 小水塘 | 河流扩展处 | 椭圆形，可养鸭子 |
| 樱花树 | 菜地旁/房屋侧 | 粉色花冠，偶尔飘落花瓣 |
| 草地 | 全场景地面 | 柔软绿色，带有深浅变化 |
| 花丛 | 散布各处 | 紫色/白色/黄色小花 |

### 4.5 装饰物件
| 物件 | 说明 |
|------|------|
| 木质篱笆 | 围绕菜地 |
| 石块 | 菜地边缘/路边点缀 |
| 陶罐 | 庭院装饰 |
| 南瓜 | 地面装饰，可互动 |
| 小鸭子 | 水塘里游动 |
| 庭院装饰 | 花盆、小灯笼等 |

## 五、UI 元素规范

### 5.1 顶部状态栏

```
┌─────────────────────────────────────────────┐
│ [头像] Lv.5 小岛主    [任务]     @1250  ♥30 │
│        经验条          收获3个南瓜   [电量]  │
└─────────────────────────────────────────────┘
```

| 元素 | 位置 | 样式 |
|------|------|------|
| 角色头像 | 左上角 | 圆形头像 + 等级标签，圆角卡片背景 |
| 经验条 | 头像右侧 | 细长进度条，暖黄色填充 |
| 任务提示 | 顶部居中 | 圆角卡片，带任务图标和文字 |
| 星币 | 右上角 | 金色图标 + 数字 |
| 爱心 | 右上角 | 粉色心形 + 数字 |
| 电量 | 右上角 | 系统电量显示 |

### 5.2 对话框/提示气泡
- 位置：顶部任务栏下方
- 样式：圆角气泡，带小尾巴指向来源
- 出现/消失：淡入淡出动画
- 内容：NPC对话/系统提示/成就通知

### 5.3 底部功能栏
统一收到右下角，只有点开的时候展开，

```
┌─────────────────────────────────────────────┐
│  [种子]  [仓库]  [商店]  [日记]  [好友] [菜单] │
└─────────────────────────────────────────────┘
```

| 按钮 | 功能 | 图标风格 |
|------|------|----------|
| 种子 | 打开种子商店 | 绿色圆形，嫩芽图标 |
| 仓库 | 查看库存 | 棕色圆形，木箱图标 |
| 商店 | 买卖物品 | 蓝色圆形，价签图标 |
| 日记 | 心情日记 | 粉色圆形，书本图标 |
| 好友 | 好友列表 | 紫色圆形，握手图标 |
| 菜单 | 设置/更多 | 灰色圆形，齿轮图标 |

- 样式：圆角卡片背景，圆形按钮排列
- 交互：点击弹出对应面板，半透明遮罩
- 按钮：按下时缩小动画 + 触感反馈

### 5.4 UI 设计原则
- 所有 UI 元素使用**圆角卡片**风格（圆角半径 8-12px）
- 图标风格：可爱、圆润、扁平
- 字体：圆润无衬线体
- 按钮：半透明白色背景 + 细边框
- 面板：从底部/侧边滑入，带半透明遮罩
- 所有 UI 不遮挡核心场景区域

## 六、地图拖拽交互

### 拖拽规则
- 支持**单指拖拽**上下左右查看大地图
- 拖拽时三层视差滚动：远景慢 → 中景正常 → 近景快
- 场景边缘**自然延展**（不出现黑边），远处渐变为森林
- 松手后回弹到默认视角（以茅草屋为中心）
- 双击空白处快速回到茅草屋

### 可探索区域（按开发阶段解锁）
| 方向 | 区域 | 解锁条件 |
|------|------|----------|
| 上方 | 森林深处 | Lv.8 砍树解锁 |
| 下方 | 码头/沙滩 | Lv.7 砍树解锁 |
| 左侧 | 岩石区/矿洞 | Lv.10 砍树解锁 |
| 右侧 | 花园 | Lv.5 砍树解锁 |
| 右上 | 美食店 | Lv.6 + 10好友 + 100星币 + 20友币 |
| 左上 | 日记小屋 | Lv.3 砍树解锁 |
| 右下 | 好友码头 | Lv.4 砍树解锁 |

### 未解锁区域显示
- 密集树林遮挡，显示半透明"需要Lv.X解锁"提示
- 砍树动画：角色挥斧 → 树倒下 → 新区域展开

## 七、动画规范

| 场景 | 动画 | 时长 |
|------|------|------|
| 角色待机 | 微微上下浮动 | 2s 循环 |
| 角色行走 | 弹跳式移动 | - |
| 种菜 | 种子落入土中 → 小芽冒出 | 0.5s |
| 浇水 | 水壶倾斜 → 水滴落下 | 0.3s |
| 作物成长 | 渐变大 + 颜色变化 | 根据品种 |
| 收菜 | 作物弹起 → 飞入仓库 | 0.4s |
| 樱花飘落 | 花瓣旋转下落 | 持续 |
| 水面波纹 | 同心圆扩散 | 3s 循环 |
| UI 弹出 | 底部滑入 + 遮罩淡入 | 0.3s |
| 砍树解锁 | 树摇晃 → 倒下 → 区域亮起 | 1.5s |

## 八、MVP(P0) 阶段最小场景

开发初期只需要渲染以下元素：
- 茅草屋（不可进入）
- 1块16宫格菜地
- 小河 + 木桥
- Q版角色（待机+行走动画）
- 基础草地 + 树木背景
- 顶部状态栏（头像/等级/星币/任务）
- 底部功能栏（种子/仓库/商店/菜单）
- 4个方向的树林遮挡（显示"需要Lv.X解锁"）

**不需要**: 樱花树/花丛/南瓜/陶罐/小鸭子/水塘/日记/好友/美食店等——这些在后续阶段逐步加入。

## 九、性能注意事项

| 项目 | 建议 |
|------|------|
| 地图渲染 | 使用瓦片地图(Tilemap)，只渲染可视区域 |
| 视差层数 | 远/中/近三层即可，不宜过多 |
| 动画帧率 | 角色30fps，UI 60fps |
| 资源加载 | 场景资源预加载，UI资源按需加载 |
| 拖拽性能 | 使用 transform 而非 left/top |
| 内存 | 装饰物件使用对象池复用 |

### 替换方法

所有场景元素使用 `position: absolute` 定位，替换只需改 HTML：

```html
<!-- 当前图片形式 -->
<div class="cottage">
  <img src="assets/cottage.png" alt="茅草屋">
</div>

<!-- 或纯 CSS 形式 -->
<div class="cottage"> ... </div>
```

CSS 中的动画（角色弹跳、树摇晃、船晃动）和层级（z-index）可以继续复用，不需要改。

### 注意事项

1. **白底素材**放在** cream 色背景**上几乎看不出来，但放在**蓝色水面**上会明显穿帮，需要透明底 PNG。
2. **水印**在 AI 生成图片右下角，原型里用 `height: 120% + object-position: center 30%` 把底部裁剪掉了。
3. 蔬菜/作物暂时用 Emoji，后续可以替换为 **序列帧动画**（种子→发芽→生长→成熟）。
4. 角色目前是正面图，建议后续做 **4 方向行走图 + 待机/浇水/收获动作** 的图集。
