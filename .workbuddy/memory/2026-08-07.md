## 花卉商店 SQL 错误修复（20:20）
- **问题**: demo2.8-island.html 点击花卉商店报 `Unknown column 'currency_type' in 'field list'`
- **根因**: MySQL `flower_config` 和 `player_flower_right` 仍是 Demo2.8 之前的旧 schema
  - flower_config 旧列名：purchase_currency/purchase_price/max_flower_level

- **迁移脚本**: `game-server/src/main/resources/db/migration-demo28-flower-schema.sql`
- **关键陷阱**:
  - 添加新列时 `AFTER seed_price` 要求 seed_price 已存在（必须先 rename 再 ADD）
  - MySQL CHECK 约束引用旧列名时，无法 rename 该列，必须先 `DROP CHECK`
  - 老数据需要逐行 UPDATE 填入 grow_seconds/yield_count/harvest_exp 的真实值
- **迁移完成后**: SQL `SELECT flower_id,name,currency_type,seed_price,grow_seconds,yield_count,harvest_exp,honey_coefficient,max_level,enabled FROM flower_config WHERE (enabled = 1)` 正确返回 8 行数据
